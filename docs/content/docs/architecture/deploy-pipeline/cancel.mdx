## Send a cancel

```bash title="Terminal"
ferry cancel DEPLOY_ID
```

The API call is `POST /api/v1/deploys/{id}/cancel`.

## The two refusals

```text title="After the switch" noCopy
too late to cancel: traffic was already switched to deploy dep-… (roll back to undo it)
```

```text title="Finished" noCopy
deploy dep-… is already canceled
```

The second message gives the final status of the deploy, here `canceled`.

## Suspend and delete

If you suspend or delete a service, the engine cancels its queued deploys and its deploys in progress in the same way.

For the user view, see [Cancel a deploy](/docs/concepts/deploys/cancel).
