## What the engine never deletes

- The <Term id="image" /> of the live deploy.
- The images of the active deploys.
- A public image that it pulled. It deletes only the tags that this server built or pinned.

## The effect on rollbacks

A [rollback](/docs/architecture/deploy-pipeline/restarts-rollbacks) can use only a deploy whose image still exists. To keep more images, start `ferryd` with a higher `--keep-images`.
