The <Term id="deploy" /> keeps a one-line `error`. The engine also writes it in the log:

```text title="Deploy log" noCopy
==> Build failed: …
==> Deploy failed: …
```

| Status | The failure was |
|---|---|
| `build_failed` | In a step before the image was ready |
| `deploy_failed` | At the start of the instances, or at the health checks |

## What to do

Correct the cause. Then deploy again.

```bash title="Terminal"
ferry deploy api --follow
```

Or [roll back](/docs/reference/cli#ferry-rollback) to an earlier deploy.
