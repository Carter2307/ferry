A <Term id="deploy" /> changes a source into <Term id="instance">instances</Term> behind the <Term id="proxy" />. The source is a git commit, an uploaded folder, an image, or the image of an earlier deploy.

The <Term id="engine" /> runs the deploy in the background. The API call that starts it only puts it in the queue and answers `202`.

This section follows one deploy through `ferry-engine`. For the user view, see [Deploys](/docs/concepts/deploys).

## Start a deploy

```bash title="Terminal"
ferry deploy api --follow
```
