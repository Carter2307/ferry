This <Term id="deploy-log" /> is from an image deploy of a web service with two instances.

The lines that start with `==> ` come from Ferry. The other lines are the output of the build or of the containers.

## Which step writes which line

| Lines | Step |
|---|---|
| `Using image`, `Pinned` | [Build](/docs/architecture/deploy-pipeline/build) |
| `Using port`, `Limits` | [Snapshot](/docs/architecture/deploy-pipeline/snapshot) |
| `Starting`, `Started instance` | [Start](/docs/architecture/deploy-pipeline/start) |
| `Waiting for`, `Health check passed` | [Health check](/docs/architecture/deploy-pipeline/health-check) |
| `Routing traffic`, `Your service is live` | [Switch](/docs/architecture/deploy-pipeline/switch) |

For the commands that read a log, see [History and logs](/docs/concepts/deploys/history).
