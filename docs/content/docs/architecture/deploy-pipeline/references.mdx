These <Term id="reference">references</Term> need the port of another service. If that service is in its first <Term id="deploy" />, the port has no value yet.

```text title="References to a port" noCopy
${{service.NAME.port}}
${{service.NAME.hostport}}
${{service.NAME.internalUrl}}
```

The deploy waits only for services that are in their first deploy. See [Env var references](/docs/reference/env-references/port-wait).
