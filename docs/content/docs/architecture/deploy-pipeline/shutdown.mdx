## The error of the deploy

A <Term id="deploy" /> in progress does not continue when <Term id="ferryd" /> stops.

| When | Error | Status |
|---|---|---|
| At shutdown | `interrupted by server shutdown` | `build_failed` or `deploy_failed` |
| At the next start | `interrupted by server restart` | `build_failed`, or `deploy_failed` if the deploy was in the state `deploying` |

The second case applies after a kill or a crash: no process was there to stop the deploy.
