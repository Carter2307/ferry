The function is `Engine::deploy`. After it finds the source, it stores the <Term id="deploy" /> with the status `queued`. Then the [queue and the worker](/docs/architecture/deploy-pipeline/queue) take the deploy.

## Refused deploys

The engine refuses a service with no source. It also refuses a suspended service, with the status code 409.

```text title="Errors" noCopy
service 'x' has no repository or image: upload code with `ferry up x`
service 'x' is suspended: resume it before deploying
```

## The first deploy of a public service

A public service with no deploy before gets an empty route immediately. While the first deploy runs, its URL answers 503 ("no healthy instances yet"), not 404.
