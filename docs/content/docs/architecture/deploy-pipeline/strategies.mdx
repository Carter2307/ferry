| Strategy | For | What the engine does |
|---|---|---|
| <Term id="blue-green">Blue-green</Term> (default) | A service with no disk | It starts the new instances next to the old instances. The old instances answer until the switch. |
| <Term id="recreate">Recreate</Term> | A service with a <Term id="disk" /> | It stops the old instance first. Then it starts the new instance. |

## Why recreate exists

Two containers cannot share a disk safely. Thus a service with a disk has no <Term id="zero-downtime" /> deploy.

For the user view, see [Scaling](/docs/concepts/scaling).
