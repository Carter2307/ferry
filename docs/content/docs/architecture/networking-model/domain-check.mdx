The proxy answers the path of the check for each host. The id tells the engine that the answer comes from this process and not from another server.

## Why a new name each time

- Only a <Term id="wildcard-record" /> answers for a name that nobody made before.
- No <Term id="dns" /> resolver has an old answer for it in its cache.

## How often

| State of the domain | The engine verifies it |
|---|---|
| Pending | Each 15 seconds |
| Active | Each 10 minutes |

After three failures in a row, an active domain gets the flag "misconfigured". Ferry continues to serve it.
