A <Term id="server-domain" /> gives a hostname to each public service. The <Term id="route-table" /> has one route for each hostname.

## The four operations

Each operation replaces the served set:

- Connect a domain.
- Verify a domain.
- Promote a domain.
- Disconnect a domain.

Ferry serves a connected domain only after the engine [verifies it](/docs/architecture/networking-model/domain-check).

For the steps that you do, see [Connect a domain](/docs/guides/domains).
