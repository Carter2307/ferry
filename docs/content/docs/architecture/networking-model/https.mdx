<Term id="https" /> needs two options of `ferryd`: `--https-addr` and `--acme-email`. With them, the proxy also does the <Term id="tls" /> work.

The <Term id="certificate">certificates</Term> come from <Term id="lets-encrypt" />, through <Term id="acme" /> with the <Term id="http-01" />.

## The rules

| Case | What the proxy does |
|---|---|
| A plain HTTP request to a host that has a certificate | It answers `308`: a redirect to HTTPS. |
| A local hostname: `*.localhost`, `.local`, `.internal`, `.test`, or an IP address | The host never gets a certificate. It stays on HTTP. |

For the full setup, see [Custom domains and HTTPS](/docs/guides/custom-domains-https).
