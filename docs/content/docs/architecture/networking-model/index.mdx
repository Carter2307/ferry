Ferry uses two kinds of connections:

- Containers talk to each other on a private Docker network.
- The outside reaches the public services only through the <Term id="proxy" /> in <Term id="ferryd" />.

The two ends of the proxy stay on the host. It listens on the public addresses that you choose. It connects to the containers through ports on `127.0.0.1`.

For the user view, see [Networking and domains](/docs/concepts/networking).
