The proxy does <Term id="load-balancing" /> with <Term id="round-robin" /> over the instances of the service that can get traffic.

## What the proxy supports

| Subject | Behavior |
|---|---|
| Clients | HTTP/1.1 and <Term id="http2" /> |
| <Term id="websocket">Websockets</Term> | The proxy passes them through. |
| Retry | A `GET` or `HEAD` with no body whose connection fails gets one retry on another instance. |
| To the app | HTTP/1.1, with the original `Host` and the proxy headers. See [the security model](/docs/architecture/security). |
