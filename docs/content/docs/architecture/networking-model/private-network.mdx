The network is a user-defined <Term id="bridge-network" />. The option `--name-prefix` sets its name. On it, the DNS of Docker changes an <Term id="alias" /> into the address of a container.

## The addresses

| To reach | Address |
|---|---|
| A service | `http://NAME:PORT`, for example `http://api:8000` |
| A datastore | `NAME:5432` (Postgres) or `NAME:6379` (Redis), or its full <Term id="connection-string" /> |

All the instances of a service share the alias. The DNS of Docker answers with the addresses of all of them.

## Do not write the addresses by hand

Use [env var references](/docs/reference/env-references):

```text title="Variables" noCopy
${{service.api.internalUrl}}
${{datastore.app-db.connectionString}}
```
