| Status | `x-ferry-error` | When |
|---|---|---|
| 400 | `bad_request` | The `Host` header is not there, or it has a bad format. |
| 404 | `not_found` | No service has this hostname. |
| 405 | `method_not_allowed` | `CONNECT`: a reverse proxy does not forward it. |
| 408 | `request_timeout` | The client stopped in the middle of its request body. |
| 503 | `suspended` | You suspended the service. |
| 503 | `no_upstreams` | No instance accepts connections yet: no deploy before, a deploy in progress, or a crash. The answer has `Retry-After: 5`. |
| 502 | `bad_gateway` | The instance refused the connection, or failed during the request. |

## Use the header

The header is <Term id="ferry-error-header" />. If a response has it, the answer comes from the proxy and not from your app.
