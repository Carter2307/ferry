The proxy listens on `--proxy-addr` (default `0.0.0.0:8080`), and on `--https-addr` for TLS. It routes each request by its <Term id="host-header" />. It ignores the port in the header.

| Hostname | Goes to |
|---|---|
| `<name>.<domain>`, for each served domain of the server | The web service or static site `<name>` |
| A <Term id="custom-domain" /> | The service that claimed it |
| `ferry.<base-domain>`, the dashboard host | The API and the dashboard (`--api-addr`) |

<Accordions>
  <Accordion title="Served domains">
    - Ferry always serves the <Term id="base-domain" /> (`--base-domain`).
    - Ferry serves a [connected domain](/docs/architecture/networking-model/domains) after its DNS reaches the server.
    - With the default base domain `localhost`, browsers resolve `*.localhost` to `127.0.0.1` with no DNS setup.
  </Accordion>
  <Accordion title="Custom domains">
    A custom domain belongs to one service only. It cannot be a hostname below a domain of the server.
  </Accordion>
  <Accordion title="The dashboard host">
    The dashboard host is on by default only for local base domains. See [the security model](/docs/architecture/security).
  </Accordion>
</Accordions>
