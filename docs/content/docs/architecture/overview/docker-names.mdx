## The names

`<prefix>` is the <Term id="name-prefix" /> of the server. The default is `ferry`.

| Resource | Name |
|---|---|
| Network | `<prefix>` |
| Image | `<prefix>/<service>:<deploy id>` |
| Service container | `<prefix>-<service>-<deploy short id>-<random>` |
| Job container | `<prefix>-job-<service>-<job short id>` |
| Datastore container and volume | `<prefix>-ds-<name>` and `<prefix>-ds-<name>-data` |
| Service disk | `<prefix>-svc-<service id>-disk` |
| Ownership marker volume | `<prefix>-owner` |

## The labels

Each <Term id="container" /> has these <Term id="container-label">labels</Term>:

| Label | Value |
|---|---|
| `ferry.managed` | `true` |
| `ferry.instance` | `<prefix>` |
| `ferry.role` | `service`, `job` or `datastore` |
| `ferry.service`, `ferry.deploy`, `ferry.job`, `ferry.datastore` | The ids that apply to this container |

See [the security model](/docs/architecture/security) for the rule "one server per data directory and prefix".
