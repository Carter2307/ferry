<Term id="ferryd" /> does not run your apps itself. It tells the <Term id="docker-daemon" /> what to do, through the <Term id="docker-engine-api" /> and through the `docker` command.

## The two crates

| Crate | Contents |
|---|---|
| `ferry-build` | It changes source into an <Term id="image" />: git fetch or archive extraction, <Term id="runtime" /> detection, and a <Term id="dockerfile" /> for native runtimes. Then it runs `docker build` with <Term id="buildkit" /> and sends the output to the deploy log. |
| `ferry-docker` | A typed wrapper over the Docker Engine API (through `bollard`): containers, images, volumes, networks, logs, stats and exec. It knows nothing about services or deploys. |
