The <Term id="engine" /> is the center of <Term id="ferryd" />. Its <Term id="crate" /> is `ferry-engine`. It implements the <Term id="trait" /> `ferry_core::Engine`, and the API calls that trait.

## What the engine uses

| Part | The engine uses it to |
|---|---|
| [The store](/docs/architecture/overview/store) | Read what must run. Write the status of each deploy. |
| [`ferry-build`](/docs/architecture/overview/docker) | Make an image from the source. |
| [`ferry-docker`](/docs/architecture/overview/docker) | Create, start and remove containers. |
| [The proxy](/docs/architecture/overview/proxy) | Update the <Term id="route-table" />. |
