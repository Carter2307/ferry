Ferry is one server process, <Term id="ferryd" />, and one command-line client, `ferry` (the <Term id="cli" />).

`ferryd` keeps the <Term id="desired-state" /> in <Term id="sqlite" />. It controls <Term id="docker" /> and builds images with the `docker` and `git` commands. It serves the public <Term id="proxy" /> and the admin <Term id="api" />.
