<Term id="ferryd" /> is the program of the server. Its <Term id="crate" /> connects all the other crates.

| Step | More |
|---|---|
| Options | [Server options](/docs/reference/server-options) |
| Lock | The file `ferryd.lock` of the [data directory](/docs/architecture/overview/data-directory). `ferryd` holds it while it runs. |
| Prefix | The <Term id="name-prefix" /> of the [Docker names](/docs/architecture/overview/docker-names). See [the security model](/docs/architecture/security). |
| Engine | The engine first repairs what a previous process left. See [At boot](/docs/architecture/reconciler/boot). |
