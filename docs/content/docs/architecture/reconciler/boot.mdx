The first three steps come before the first <Term id="reconciler-pass" />.

## Deploys that were not complete

| Status at the stop | New status |
|---|---|
| `queued` or `building` | `build_failed` |
| `deploying` | `deploy_failed` |

The error is `interrupted by server restart`. The job runs with the status pending or `running` get the same error.

The containers of these deploys never got traffic. The first pass removes them immediately.

See also [Server shutdown and restart](/docs/architecture/deploy-pipeline/shutdown).
