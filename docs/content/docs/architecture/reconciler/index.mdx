The <Term id="store" /> has the <Term id="desired-state" />. Docker has the <Term id="actual-state" />. The <Term id="reconciler" />, in `ferry-engine`, makes Docker agree with the store.

The reconciler does three things:

- It restarts a service that crashed.
- It applies a new instance count.
- It cleans up after a server that stopped in the middle of an operation.

For the effect on your apps, see [Self-healing](/docs/concepts/self-healing).
