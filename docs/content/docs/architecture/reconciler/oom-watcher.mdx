The <Term id="oom-watcher" /> follows the `oom` events of Docker for the containers of this server.

```text title="Server log" noCopy
instance a1b2c3 of service 'web' ran out of memory (limit 512 MiB) — raise the service's memory limit
```

## Why it exists

The <Term id="kernel" /> does the <Term id="oom" />. Docker then restarts the container by itself. Then Docker clears the flag that tells about the kill.

Without the watcher, nobody sees a container that crashes again and again at its memory limit.
