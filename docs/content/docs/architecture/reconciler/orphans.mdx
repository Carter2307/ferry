## What the reconciler removes

| Container | Result |
|---|---|
| Its service or datastore is not in the <Term id="store" /> | Removed |
| The container of a job run that is complete or unknown | Removed |
| Its `ferry.role` is unknown | Left alone |

All these containers have the <Term id="name-prefix" /> of this server. The reconciler never touches a container of another prefix.

## No false orphan

The reconciler lists the containers before it reads the store. Thus it never sees a resource that you create during the pass as an <Term id="orphan" />.
