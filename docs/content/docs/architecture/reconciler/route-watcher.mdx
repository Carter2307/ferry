The <Term id="route-watcher" /> is a task that runs next to the passes of the <Term id="reconciler" />.

## Why it exists

Docker publishes each instance on a random <Term id="host-port" />. When Docker restarts a crashed container, the port can change. See [Why 127.0.0.1](/docs/architecture/networking-model/why-localhost).

A full pass comes only each 10 seconds. The watcher does not wait for the next pass. It updates the routes of that service when the new instance accepts connections.
