| State of the service | Route |
|---|---|
| Instances run and accept TCP connections | <Term id="round-robin">Round-robin</Term> over their `127.0.0.1:<host port>` addresses |
| No instance accepts connections yet | A 503 page with `Retry-After` |
| Suspended | A 503 "suspended" page |
| Deleted | No route: 404 for its hostnames |
| Private services, workers, cron jobs | No route: they are not public |

The <Term id="route-table" /> is in the memory of the proxy. The proxy reads it for each request.

## The route of the dashboard

`ferryd` installs the route of the dashboard, `ferry.<base-domain>`, when this route is on. The reconciler never removes it.

See also [Errors of the proxy](/docs/architecture/networking-model/proxy-errors).
