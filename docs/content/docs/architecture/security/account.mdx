A server has one <Term id="admin-account" />: an email and a password of 8 characters or more. The server stores an <Term id="argon2id" /> <Term id="password-hash" /> of the password, never the password.

The account controls the full server. No other users, roles or permissions per service exist.

## How each caller proves its identity

| Caller | Proof |
|---|---|
| You, in the dashboard | Your email and password, then the [session cookie](/docs/architecture/security/sessions) |
| The CLI, scripts and CI | An [API token](/docs/architecture/security/api-tokens) |
| Scripts on the server | The [server token](/docs/architecture/security/server-token) |
| A deploy hook | The [key in its URL](/docs/architecture/security/hook-keys) |
| GitHub | The [signature of each delivery](/docs/architecture/security/github-webhooks) |

## Create or repair the account

- A new server has no account. [Create it with the setup code](/docs/architecture/security/setup-code).
- If you forget the password, [replace it on the server](/docs/architecture/security/reset-password).
