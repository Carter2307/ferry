The <Term id="cli" />, scripts and <Term id="ci" /> prove their identity with an <Term id="api-token" />. A token is `fy_` and then 40 <Term id="hex">hex characters</Term>.

## Create a token

In the dashboard, open **Server → Account**. Give the token a name. An expiry is optional.

The dashboard shows the token one time, when you create it. The server stores only its <Term id="sha-256" /> hash. The list shows the last 4 characters of each token and the time of its last use.

## Send a token

```bash title="Terminal"
curl -H "Authorization: Bearer $FERRY_TOKEN" http://127.0.0.1:7878/api/v1/services
```

A token has full access. Read [What a token can do](/docs/architecture/security/token-access).
