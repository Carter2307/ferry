```text title="The path"
/.well-known/ferry-domain-check/<token>
```

The <Term id="proxy" /> answers this path for each host, with no authentication.

## What the answer contains

| Part | Rule |
|---|---|
| The token | The same token as in the path. It must be alphanumeric. |
| An id | The process made it up when it started. |

The answer tells nothing about the services.
