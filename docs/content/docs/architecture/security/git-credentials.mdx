A repository URL can contain a token. Ferry <Term id="redact">redacts</Term> it: it writes `***` in its place.

| You give | Ferry writes |
|---|---|
| `https://user:token@github.com/…` | `https://***@github.com/…` |

## Where Ferry redacts the token

- deploy logs
- error messages
- the change lists of a <Term id="blueprint" />
- webhook answers

## What to do

Ferry keeps a repository URL with its credentials in [the data directory](/docs/architecture/security/data-directory). Protect that directory and its backups.

A [connected git account](/docs/architecture/security/git-connections) is another way to read a private repository.
