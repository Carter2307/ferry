A GitHub <Term id="webhook" /> does not use the account or an API token. Its proof is an <Term id="hmac" /> signature made with the <Term id="webhook-secret" />.

## The rules

| Rule | Detail |
|---|---|
| Off by default | The endpoint answers 404 until you set `--github-webhook-secret`. |
| Signature | `X-Hub-Signature-256`: HMAC-SHA256 of the raw body, compared in <Term id="constant-time">constant time</Term>. |
| No <Term id="replay" /> | Ferry ignores a delivery if it processed the same body or the same delivery id before. |

## Turn it on

```bash title="On the server"
ferryd --github-webhook-secret <secret>
```

Give the same secret to GitHub. [GitHub auto-deploy](/docs/guides/github-auto-deploy) shows each step. The [API overview](/docs/reference/api-overview/github-webhook) has the details.
