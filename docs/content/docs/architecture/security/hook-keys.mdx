```text title="The URL of a deploy hook"
/hooks/deploy/<service id>?key=<key>
```

Webhooks do not use the account or an API token. Each one has its own secret. For a <Term id="deploy-hook" />, the secret is the key in the URL.

The path takes the service id only, because names are easy to guess.

<Callout type="warning" title="The URL is a password">
Each person who has the URL can start deploys of the service, but nothing else.
</Callout>

## If the URL leaks

Replace the key:

```bash title="Terminal"
ferry deploy-hook rotate NAME
```

[Deploy hooks](/docs/concepts/deploys/deploy-hooks) shows how to use a hook. The [API overview](/docs/reference/api-overview/deploy-hooks) has the details.
