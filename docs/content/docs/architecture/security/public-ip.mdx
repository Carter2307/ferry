A server behind <Term id="nat" /> does not know its <Term id="public-address" />. Ferry needs this address to show the <Term id="dns-record">DNS records</Term> of a domain.

## The rules

- This is the only request that Ferry makes to a third party on its own.
- Ferry makes it only after a domain that is not local exists.
- `--public-ip` replaces it.

## Prevent the request

```bash title="On the server"
ferryd --public-ip <IP>
```

With `--public-ip`, Ferry asks no service.
