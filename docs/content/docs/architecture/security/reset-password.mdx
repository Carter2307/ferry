---
title: A forgotten password
description: If you forget the password, replace it with a command on the server.
---

```bash title="On the server"
ferryd reset-password
```

Run the command on the server. It changes the data directory, thus only a person with access to the server can use it. The command works while the server runs.

The reference of [`ferryd reset-password`](/docs/reference/server-options#ferryd-reset-password) lists its options.

<Accordions>
  <Accordion title="In a script">
    If standard input is not a terminal, the command reads one line from standard input. That line is the new password.
  </Accordion>
  <Accordion title="Another data directory">
    The command uses `./ferry-data`. If your data directory is in another place, add `--data-dir`.
  </Accordion>
</Accordions>
