A secret is a value that only your app must know: a password, a token, a key. Ferry keeps each secret out of the places where secrets leak.

## Each secret has a page

| Secret | Protection |
|---|---|
| Variables during a build | [Secrets in a build](/docs/architecture/security/build-secrets) |
| Datastore passwords | [Datastore passwords](/docs/architecture/security/datastore-passwords) |
| A token in a repository URL | [Repository credentials](/docs/architecture/security/git-credentials) |
| The secrets of a connected git account | [Connected git accounts](/docs/architecture/security/git-connections) |
| All of them, on the disk | [The data directory](/docs/architecture/security/data-directory) |

<Callout type="warning" title="The API gives secrets to each authenticated caller">
The API returns variable values and datastore passwords to each caller that has the session or an API token. The dashboard shows them so that you can copy <Term id="connection-string">connection strings</Term>.
</Callout>
