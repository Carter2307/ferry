A <Term id="graceful-shutdown" /> stops `ferryd`, not your apps. A <Term id="signal" /> starts it.

## Stop the server

```bash title="On the server"
ferryd stop
```

`ferryd stop` sends `SIGTERM`. For a server in the foreground, press <kbd>Ctrl</kbd>+<kbd>C</kbd>: this sends `SIGINT`.

## A second signal

A second signal stops `ferryd` immediately. The <Term id="exit-code" /> is 130.

## What a shutdown does to a deploy

A deploy in progress fails. See [If the server stops during a deploy](/docs/concepts/deploys/interrupted).
