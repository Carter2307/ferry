The limit makes it slow to guess the password. It applies to sign-ins and to attempts to create the account.

| Rule | Value |
|---|---|
| Failures before the refusal | 10 in 5 minutes |
| Answer during the refusal | 429 `too_many_attempts` |
| End of the refusal | When the oldest failure is 5 minutes old |

<Callout type="warning" title="The limit is not per IP address">
The server has one counter for all callers. A person who can reach the API can thus delay the sign-in of the administrator. This is one more reason to keep the API on localhost or behind HTTPS.
</Callout>

## What to do

Keep the API away from the internet. See [What listens where](/docs/architecture/security/exposure) and [Reach the API through SSH](/docs/architecture/security/ssh-tunnel).
