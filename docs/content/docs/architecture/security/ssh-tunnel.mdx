This is the safer default for a production server. The API stays on <Term id="localhost" />, and the <Term id="ssh-tunnel" /> encrypts the traffic.

## Do it

<Steps>
<Step>

### Open the tunnel

Run this command on your machine. Keep it open.

```bash title="Terminal"
ssh -L 7878:127.0.0.1:7878 you@your-server
```

</Step>
<Step>

### Connect the CLI

Run this command in a second terminal.

```bash title="Terminal"
ferry login --server http://127.0.0.1:7878
```

</Step>
</Steps>

The dashboard is at `http://127.0.0.1:7878` in your browser.

The other way is [the dashboard on a hostname](/docs/architecture/security/dashboard-host), with HTTPS.
