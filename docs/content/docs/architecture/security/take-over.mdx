The file `instance_id` is the claim of a data directory on its <Term id="name-prefix" />. A data directory with no `instance_id` cannot prove that the prefix is its own.

## Take the prefix back

```bash title="On the server"
ferryd --take-over
```

`--take-over` is only for a data directory that lost its `instance_id`.

<Callout type="danger" title="Never while another server uses the prefix">
The server that takes over removes the containers of the other server as <Term id="orphan">orphans</Term>.
</Callout>

See [One server per data directory and prefix](/docs/architecture/security/one-server) for the rule that this flag overrides.
