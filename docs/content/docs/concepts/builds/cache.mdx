The <Term id="build-cache" /> of Docker makes the next builds fast. Docker installs the <Term id="dependency">dependencies</Term> again only when a manifest changes: `package.json`, `requirements.txt`, `go.mod`…

## Build with no cache

```bash title="Terminal"
ferry deploy api --clear-cache
```

In the dashboard, open the **Manual deploy** menu. Choose **Clear build cache & deploy**.

The two ways run `docker build --no-cache`. Use them, for example, to get new versions of dependencies that have no pinned version.
