## The files

These files tell Ferry the <Term id="runtime" />.

| File in the root directory | Runtime |
|---|---|
| `Dockerfile` | `docker` |
| `package.json`, `bun.lockb` or `bun.lock` | `node` |
| `requirements.txt`, `pyproject.toml` or `Pipfile` | `python` |
| `go.mod` | `go` |
| `Cargo.toml` | `rust` |
| `Gemfile` | `ruby` |
| `index.html` | `static` |

Ferry looks in the <Term id="root-directory" /> only, not in the folders below it.

## See the result

```text title="Deploy log" noCopy
==> Detected Node.js runtime
```

## If no file is there

| Case | Result |
|---|---|
| The Dockerfile path is not `Dockerfile` (`--dockerfile`) | The runtime is `docker`. |
| The service is a static site | nginx serves the files as they are. |
| All other cases | The build fails with `could not detect the runtime`. |

To correct the failure, add one of the files, or [set the runtime](/docs/concepts/builds/runtimes).
