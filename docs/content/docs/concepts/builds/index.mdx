A <Term id="build" /> makes a Docker <Term id="image" /> from your code. Each deploy of a git service or an upload service builds an image.

Ferry finds the <Term id="runtime" /> of your code: Node.js, Python, Go, Rust, Ruby or static files. Then it writes the <Term id="dockerfile" /> for you. Thus you can deploy with no knowledge of Docker.

For full control, commit your own Dockerfile. Ferry then uses it.

A service that deploys a prebuilt image has no build.

## Start a build

```bash title="Terminal"
ferry deploy api --follow
```

The build is the first step of a [deploy](/docs/concepts/deploys). `--follow` shows its output.
