## The four limits

| Subject | Limit |
|---|---|
| Uploads | A `ferry up` <Term id="archive" /> can be 512 <Term id="mib">MiB</Term> at most, compressed. On the server, it can expand to 2 GiB and 200,000 files, directories and links at most. |
| Registries | Ferry pulls public images only. It has no <Term id="registry" /> authentication. |
| Submodules | Ferry does not fetch <Term id="submodule">git submodules</Term>. |
| Architecture | The Docker of the server builds and runs the images, for the <Term id="cpu-architecture" /> of the server. |
