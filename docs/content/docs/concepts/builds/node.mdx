## The defaults

| Step | What Ferry does |
|---|---|
| Node.js version | It comes from `engines.node` in `package.json`. Ferry uses 22 when the range allows it. If not, Ferry uses the newest major version that the range allows. |
| Package manager | The <Term id="package-manager" /> comes from the `packageManager` field or the <Term id="lockfile" />: npm, Yarn, pnpm or Bun. Yarn and pnpm run through Corepack. |
| Install with npm | `npm ci` when there is a `package-lock.json`. If not, `npm install`. |
| Build | The `build` script of `package.json`, if there is one. |
| Start | `npm start` when there is a `start` script. With Yarn 2+: `yarn start`. With Bun: `bun run start`. |
| Start with no `start` script | `node` with the `main` file, `server.js`, `index.js` or `app.js`. |

  <Accordion title="Your own commands">
