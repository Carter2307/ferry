## Set the publish directory

```bash title="Terminal"
ferry update docs --build-cmd "cd docs && npm ci --include=dev && npm run build" --publish-dir docs/out
```

## What nginx serves

| <Term id="publish-directory">Publish directory</Term> (`--publish-dir`) | With a build step | With no build step |
|---|---|---|
| Set, for example `dist` | That directory. The build fails if it does not exist. | That directory |
| `.` | The full root directory after the build | The root directory |
| Not set | The first of `dist`, `build`, `out`, `public`, `_site` and `site` that the build made. The build fails if there is none. | See below |

## Not set, with no build step

Ferry uses the first of these that is true:

1. The <Term id="root-directory" /> has an `index.html`: nginx serves the root directory.
2. One of the six directories has an `index.html`: nginx serves the first one.
3. If not, nginx serves the root directory.
