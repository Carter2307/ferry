## The defaults

| Step | What Ferry does |
|---|---|
| Base image | The <Term id="base-image" /> is `python:<version>-slim`. The version comes from `.python-version` or `runtime.txt` (`python-3.11.4`). The default is 3.12. |
| Install with `requirements.txt` | `pip install -r requirements.txt` |
| Install with `pyproject.toml` | uv when there is a `uv.lock`. Poetry for Poetry projects. If not, `pip install .` or the dependencies of the project. |
| Install with `Pipfile` | Pipenv |
| Build | None by default. Your build command runs after the install. |
| Start | `python main.py`. If that file is not there, `python app.py`. |

For a full generated file, see the [example](/docs/concepts/builds/generated).
