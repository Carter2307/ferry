A <Term id="monorepo" /> needs a root directory. The root directory becomes the <Term id="build-context" /> of Docker.

## Set the root directory

```bash title="Terminal"
ferry create api --repo https://github.com/you/monorepo --root-dir services/api
```

In a <Term id="blueprint" />, the field is `rootDir`. The path must be relative and in the repository.

```text title="Deploy log" noCopy
==> Using root directory ./services/api
```

## What starts from the root directory

All other paths are relative to the <Term id="root-directory" />:

- the files of the runtime detection
- the Dockerfile path
- the `Procfile`
- the publish directory

## If the build needs files outside

Examples are a shared library or design tokens. Build from the repository root, and use `cd` in your build command.

```bash title="Terminal"
ferry update docs --build-cmd "cd docs && npm ci --include=dev && npm run build" --publish-dir docs/out
```
