## The defaults

| Step | What Ferry does |
|---|---|
| Base image | The <Term id="base-image" /> is `ruby:<version>-slim`. The version comes from `.ruby-version` or from the `ruby` line of the Gemfile. The default is 3.3. |
| System tools | `build-essential`, `git`, `libpq-dev`, `libyaml-dev` and `pkg-config`. Gems with native extensions need them. |
| Dependencies | `bundle install` |
| Build | None by default. Your build command runs after the install. |
| Start | With a `config.ru`: the command below. |

```bash title="The default start command" noCopy
bundle exec rackup -o 0.0.0.0 -p ${PORT:-10000}
```

<Accordions>
  <Accordion title="MySQL">

  <Accordion title="A project with no config.ru">

  </Accordion>
