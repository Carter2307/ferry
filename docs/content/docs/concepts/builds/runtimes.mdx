## The runtimes

| <Term id="runtime">Runtime</Term> | Ferry makes the image with |
|---|---|
| `auto` (default) | The runtime that it [detects](/docs/concepts/builds/detection) from the files |
| `docker` | [Your Dockerfile](/docs/concepts/builds/dockerfile) |
| `image` | No build: Ferry pulls the image of the service. Ferry sets this runtime when the service has an image. |
| `node` | A generated [Node.js](/docs/concepts/builds/node) Dockerfile (npm, Yarn, pnpm or Bun) |
| `python` | A generated [Python](/docs/concepts/builds/python) Dockerfile |
| `go` | A generated [Go](/docs/concepts/builds/go) Dockerfile |
| `rust` | A generated [Rust](/docs/concepts/builds/rust) Dockerfile |
| `ruby` | A generated [Ruby](/docs/concepts/builds/ruby) Dockerfile |
| `static` | A generated nginx image, after an optional [build step](/docs/concepts/builds/static-build) |

## Set the runtime

```bash title="Terminal"
ferry update api --runtime node
```

In the dashboard, use the **Settings** page.

<Callout type="warning" title="The runtime must agree with the files">
`--runtime node` with no `package.json` fails. The message names the file that is not there, and the runtime that the project seems to use.
</Callout>

<Accordions>
  <Accordion title="Other names for a runtime">
    Ferry accepts some other names, such as `nodejs` and `bun` for `node`, `python3` for `python` and `golang` for `go`.
  </Accordion>
</Accordions>
