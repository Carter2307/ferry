A Rust build uses two images. The first image has the Rust tools and compiles the app. The second image only runs the <Term id="binary" />.

## The defaults

| Step | What Ferry does |
|---|---|
| Build image | `rust:1-slim-bookworm` |
| Run image | `debian:bookworm-slim` |
| Dependencies | Cargo fetches them. Ferry keeps the registry and the target directory in build caches between builds. |
| Build | `cargo build --release`. Ferry installs the binary in `/usr/local/bin`. |
| Start | The binary that `default-run` names. If there is none, the binary of the package. If there is none, the first `[[bin]]` target. |
