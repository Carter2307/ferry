A <Term id="static-site" /> is the `static` service type, or the `static` runtime. <Term id="nginx" /> serves it.

## Deploy a folder of files

A folder of plain files with an `index.html` needs no build.

```bash title="Terminal"
ferry up my-site --type static --dir ./public
```

## How nginx serves the files

- For `/about`, nginx looks for `about`, then `about/index.html`, then `about.html`.
- A page that does not exist gets a 404 status, with your `404.html` if there is one.
- nginx compresses the answers with gzip.
- nginx never serves dotfiles (`.env`, `.git`…), but it serves the files below `/.well-known/`.

For the two options, see [The build of a static site](/docs/concepts/builds/static-build) and [Publish directory](/docs/concepts/builds/publish-directory).

  <Accordion title="Files that Ferry removes">
    When nginx serves the full root directory, Ferry removes `Dockerfile.ferry` and `.git` from it.
  </Accordion>
  <Accordion title="The generated Dockerfile of a static site with no build step">

```dockerfile title="Dockerfile.ferry"
# Generated by Ferry: static site served by nginx.
# Commit your own Dockerfile to customize the build.
FROM nginx:alpine
RUN rm -rf /usr/share/nginx/html/* \
 && printf '%s\n' \
    'server {' \
    '    listen 80;' \
    '    server_name _;' \
    '    root /usr/share/nginx/html;' \
    '    index index.html index.htm;' \
    '    absolute_redirect off;' \
    '    gzip on;' \
    '    gzip_vary on;' \
    '    gzip_min_length 256;' \
    '    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json application/xml application/manifest+json image/svg+xml;' \
    '    location / {' \
    '        try_files $uri $uri/ $uri.html =404;' \
    '    }' \
    '    location ~ /\.(?!well-known(/|$)) {' \
    '        return 404;' \
    '    }' \
    '    error_page 404 /404.html;' \
    '}' \
    > /etc/nginx/conf.d/default.conf
COPY . /usr/share/nginx/html/
RUN rm -rf /usr/share/nginx/html/Dockerfile.ferry* /usr/share/nginx/html/.git
EXPOSE 80
```
