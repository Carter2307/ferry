<Callout type="warning" title="Ferry does not back up datastores">
Make each <Term id="backup" /> yourself, on a schedule. When you [delete a datastore](/docs/concepts/datastores/delete), you lose its data.
</Callout>

## Make a backup of Postgres

```bash title="Terminal"
docker exec ferry-ds-app-db pg_dump -U app_db app_db > app-db.sql
```

The command runs <Term id="pg-dump" /> in the <Term id="container" /> of the <Term id="datastore" /> `app-db`. `app_db` is the user and the database. The result is the file `app-db.sql`.

[Production setup](/docs/guides/production) tells you what else to back up.
