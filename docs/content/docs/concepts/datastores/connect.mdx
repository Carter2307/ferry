## Set the variable

Give the URL of the <Term id="datastore" /> to your app in an <Term id="env-var" />.

```bash title="Terminal"
ferry env set api 'DATABASE_URL=${{datastore.app-db.connectionString}}'
ferry env set worker 'REDIS_URL=${{datastore.cache.connectionString}}'
```

`connectionString` is the <Term id="internal-url" />. It works on the <Term id="private-network" /> only.

<Callout type="warning" title="Do not paste the URL">
In a <Term id="service" />, use a <Term id="reference" />. Then the service always gets the current value.
</Callout>

## Other properties

A reference can also give one part of the URL.

| Property | Value |
|---|---|
| `host`, `port` | The internal host and port |
| `user`, `password`, `database` | The parts of the connection string |
| `externalConnectionString` | The external URL |

[Environment](/docs/concepts/environment) explains the references. For a full example with migrations, see [Deploy an app with Postgres](/docs/guides/postgres-app).
