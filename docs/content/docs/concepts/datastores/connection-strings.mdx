A <Term id="connection-string" /> is one URL with the user, the password, the host, the port and the database. The two URLs go to the same <Term id="datastore" />. Only the host and the port are different.

## The two URLs

| URL | Format | Use it from |
|---|---|---|
| <Term id="internal-url">Internal</Term> | `postgresql://USER:PASSWORD@NAME:5432/DATABASE` <br /> `redis://default:PASSWORD@NAME:6379` | Services and jobs, on the [private network](/docs/concepts/networking) |
| <Term id="external-url">External</Term> | The same, with `127.0.0.1:<host port>` | The server itself, or your machine through an <Term id="ssh-tunnel" /> |

## Use them

- For a service, see [Connect a service](/docs/concepts/datastores/connect).
- For your machine, see [Connect from your machine](/docs/concepts/datastores/external).
