---
title: Delete a datastore
description: A delete removes the container and its volume. You lose the data, and there is no undo.
---

```bash title="Terminal"
ferry db rm app-db
```

<Callout type="warning" title="There is no undo">
The command removes the <Term id="container" /> **and its <Term id="volume" />**. [Back up the data](/docs/concepts/datastores/backup) first.
</Callout>

## If a service uses the datastore

Ferry refuses, and lists each service that has a <Term id="reference" /> to the <Term id="datastore" />.

```text title="Terminal" noCopy
error: still in use — re-run with --force to delete it anyway: datastore 'app-db' is referenced by service 'api' (DATABASE_URL); they would fail to deploy or restart without it. Remove the references first, or delete with force=true (conflict)
```

Remove the references first. Or delete the datastore anyway:

```bash title="Terminal"
ferry db rm app-db --force
```

Then those services fail at their next deploy or restart.
