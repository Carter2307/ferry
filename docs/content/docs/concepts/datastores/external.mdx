On the server itself, use the <Term id="external-url" /> directly. From your machine, open an <Term id="ssh-tunnel" /> first.

<Steps>
<Step>

### Get the external URL

```bash title="Terminal"
ferry db show app-db
```

Read the line `External URL`. The number after `127.0.0.1:` is the <Term id="host-port" />.

</Step>
<Step>

### Open the tunnel

```bash title="Terminal"
ssh -L 62975:127.0.0.1:62975 you@your-server
```

</Step>
<Step>

### Connect

```bash title="Terminal"
psql 'postgresql://app_db:…@127.0.0.1:62975/app_db'
```

<Term id="psql" /> is the client of Postgres.

</Step>
</Steps>

<Accordions>
  <Accordion title="When the port changes">
    Ferry chooses the external port one time, when it creates the datastore. The port changes only if a different process takes it while the container does not run. `ferry db show` always shows the current port.
  </Accordion>
  <Accordion title="The host in the external URL">
    `--advertise-host` changes the host that Ferry writes in the external URLs. It does not change where the port listens.
  </Accordion>
</Accordions>
