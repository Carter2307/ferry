A <Term id="datastore" /> is a <Term id="postgres" /> or <Term id="redis" /> server that Ferry runs for you. It is one <Term id="container" /> with its data on one Docker <Term id="volume" />. It has its own memory and CPU limits.

Your services use its <Term id="internal-url" /> on the <Term id="private-network" />. On the server, you use its <Term id="external-url" />.

Compare it with an office. The container is the clerk who answers. The volume is the cabinet that keeps the papers. A new clerk finds the same papers.

## Create a datastore

```bash title="Terminal"
ferry db create app-db --wait
```
