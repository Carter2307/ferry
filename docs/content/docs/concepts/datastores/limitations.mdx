## The limits

| What | The rule |
|---|---|
| One container | A datastore has no <Term id="replica" />, no <Term id="high-availability" /> and no <Term id="connection-pooler" />. |
| No change after creation | You can change only the [memory and CPU limits](/docs/concepts/datastores/limits). There is no version upgrade, no new password and no new name. |
| No disk quota | The volume can grow until the disk of the server is full. |
| Two kinds | Ferry has only Postgres and Redis datastores. |

## Other databases

Run each other database as a [private service](/docs/concepts/services) with a [disk](/docs/concepts/scaling/disks).
