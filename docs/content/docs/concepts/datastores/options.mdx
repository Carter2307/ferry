```bash title="Terminal"
ferry db create reports --version 17 --database reports --user analyst
```

## The options

| Option | Postgres | Redis |
|---|---|---|
| Name | 1 to 40 characters: lowercase letters, digits or `-`. The first character is a letter. | The same |
| Version (`--version`) | The major version. Default: `16`. | Default: `7`. |
| Image | `postgres:<version>-alpine` | `redis:<version>-alpine` |
| Database (`--database`) | Default: the name, with `_` in the place of `-`. | Not supported |
| User (`--user`) | Default: the name of the database. | Always `default` |
| Password | 32 random hex characters | The same |
| Memory limit (`--memory`) | Default: the limit of the server (`--default-memory-limit`, 512 MiB). | The same |
| CPU limit (`--cpu`) | Default: the limit of the server (`--default-cpu-limit`, 1 CPU). | The same |

## The rules

- Services and <Term id="datastore">datastores</Term> share one set of names.
- A version has only digits and dots (`16`, `7.2`). Ferry pulls the official <Term id="alpine" /> <Term id="image" /> with that tag.
- You can change the limits later. See [Memory and CPU limits](/docs/concepts/datastores/limits).
