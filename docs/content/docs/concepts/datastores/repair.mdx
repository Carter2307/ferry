The <Term id="reconciler" /> repairs a <Term id="datastore" /> with no action from you.

## What Ferry repairs

| Case | What Ferry does |
|---|---|
| The <Term id="container" /> of an `available` datastore stopped or disappeared. | Ferry starts it, or makes it again. |
| The creation of the datastore failed. | Ferry tries again after 1 minute. Then the delay grows, up to 30 minutes. |

## If the datastore has no more memory

`ferryd` writes this line in its log:

```text title="Log of ferryd" noCopy
datastore 'app-db' ran out of memory (limit 1 GiB) — raise the datastore's memory limit
```

If the datastore stops, Docker starts it again. To stop the cause, [raise the memory limit](/docs/concepts/datastores/limits).

[Self-healing](/docs/concepts/self-healing) explains the reconciler.
