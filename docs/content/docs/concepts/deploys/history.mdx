The command shows the 20 newest deploys. Add `-n` for more. The cause of each failed deploy is at the end.

## Read the log of one deploy

```bash title="Terminal"
ferry logs --deploy dep-ba5a7fce730d4061aaa7      # the full log
ferry logs --deploy dep-ba5a7fce730d4061aaa7 -f   # continue while the deploy runs
```

In the dashboard, open the deploy from the **Deploys** page.

## What is in the log

| Lines | From |
|---|---|
| `==> …` | Ferry |
| Build output | Docker, during the build |
| `[e5725a] …` | A new instance, during the health check |
