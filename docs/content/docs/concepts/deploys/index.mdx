A <Term id="deploy" /> is one release of a <Term id="service" />. Ferry starts the new version next to the old version. Then Ferry moves the traffic.

If the new version fails, Ferry removes it. The old version stays online.

## Start a deploy

```bash title="Terminal"
ferry deploy api --follow
```

`--follow` shows the log until the deploy is live.
