A deploy does not continue after a restart of `ferryd`. Deploys in the queue fail too.

| How `ferryd` stopped | Error of the deploy |
|---|---|
| A normal shutdown | `interrupted by server shutdown` |
| A kill or a crash | `interrupted by server restart` (written when `ferryd` starts again) |

The status is `build_failed` or `deploy_failed`.

## What to do

```bash title="Terminal"
ferry deploy api --follow
```
