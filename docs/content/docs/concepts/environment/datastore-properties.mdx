The kind is `datastore`. You can also write `db` or `database`.

```bash title="Terminal"
ferry env set api 'DATABASE_URL=${{datastore.app-db.connectionString}}'
```

## The properties

| Property | Aliases | Value |
|---|---|---|
| `connectionString` | `url`, `internalUrl` | URL on the <Term id="private-network" />, for example `postgresql://app_db:…@app-db:5432/app_db` |
| `externalConnectionString` | `externalUrl` | URL through the port published on the server, with the `--advertise-host` host |
| `host` | `hostname` | The datastore name, for example `app-db` |
| `port` | | `5432` (Postgres) or `6379` (Redis) |
| `user` | `username` | The Postgres user, or `default` for Redis |
| `password` | | The generated password |
| `database` | `databaseName` | The Postgres database name (Redis has none) |

A <Term id="connection-string" /> is the URL that your app uses to connect to the <Term id="datastore" />. See [Datastores](/docs/concepts/datastores) and [Datastore ports](/docs/concepts/networking/datastore-ports).
