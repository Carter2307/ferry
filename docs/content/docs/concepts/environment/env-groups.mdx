An <Term id="env-group" /> is a set of variables with a name. You link it to each <Term id="service" /> that needs the same values.

## Use an env group

```bash title="Terminal"
ferry env-group create shared LOG_LEVEL=info REGION=eu
ferry env-group link api shared        # prints: Restart to apply: ferry restart api
ferry env-group set shared REGION=us   # restarts the linked live services
ferry env-group show shared            # variables and linked services
ferry env-group unlink api shared
ferry env-group rm shared
```

A group name has 1 to 64 characters: letters, digits, `-`, `_` or `.`.

## What restarts

| Action | Result |
|---|---|
| `link`, `unlink` | Nothing restarts. The change applies at the next deploy or restart of the service. |
| `set`, `unset` | Ferry restarts each linked live service whose <Term id="merged-env" /> changed. Add `--no-restart` to prevent it. |
| `rm` | Ferry refuses if the group has a link. |
| `rm --force` | Ferry deletes the group. The linked services lose its variables at their next restart. |
| `rm --force --restart` | Ferry deletes the group and restarts the linked services immediately. |
