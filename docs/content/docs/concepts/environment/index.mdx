Each <Term id="service" /> has its own <Term id="env-var">environment variables</Term>. To share variables, put them in an <Term id="env-group" /> and link the group to your services.

A value can be a <Term id="reference" /> to a <Term id="datastore" /> or to a different service: `${{…}}`. Ferry puts the real value there when the service starts.

## Set a variable

```bash title="Terminal"
ferry env set api LOG_LEVEL=info 'DATABASE_URL=${{datastore.app-db.connectionString}}'
```
