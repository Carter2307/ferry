## The rules

| Part | Rule |
|---|---|
| Key | Not empty. 256 characters at most. No `=`, no whitespace, no NUL byte. One time for each service or group. |
| Value | 32 <Term id="kib" /> at most. No NUL byte. |
| Total | The keys and values of one service or one <Term id="env-group" />: 256 KiB at most. |
| Merged total | The <Term id="merged-env" /> of a service (its groups and its own variables): 256 KiB at most. |

## See the variables of a service

```bash title="Terminal"
ferry env api                    # the service's own variables
ferry env ls api --effective     # merged with its env groups
```
