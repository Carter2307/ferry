This page is for the services that listen: <Term id="web-service">web services</Term>, <Term id="private-service">private services</Term> and <Term id="static-site">static sites</Term>. An app that reads `PORT` works with no configuration.

## How Ferry chooses the port

Ferry uses the first value that it finds:

1. the port setting of the service (`--port`, `port:` in a <Term id="blueprint" />)
2. a `PORT` variable that you set
3. the hint of the build: `80` for static sites that nginx serves
4. the port that the <Term id="image" /> `EXPOSE`s, if it exposes exactly one
5. the server default, `--default-port` (`10000`)

## An app with a fixed port

If your app listens on a fixed <Term id="port" />, set it with `--port`.

```bash title="Terminal"
ferry update api --port 3000
```

<Callout type="warning" title="Do not set PORT to a different value">
If you set `PORT` to a value different from the port setting, the deploy log gives a warning. The app then listens on the wrong port.
</Callout>
