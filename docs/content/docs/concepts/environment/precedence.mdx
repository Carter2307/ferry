Ferry merges the environment of a service in this order. This is the <Term id="precedence" />:

1. the variables that Ferry [injects](/docs/concepts/environment/injected-variables) (`PORT`, `FERRY_*`)
2. its <Term id="env-group">env groups</Term>, in the order of the links
3. its own variables

## See the result

  lines={[

The command shows the <Term id="merged-env" />.

- `shared` sets `LOG_LEVEL=info`.
- `extra` sets `LOG_LEVEL=debug`. You linked it later.
- The own `LOG_LEVEL=warn` of the service wins.

Without the own value, the service gets `debug`.
