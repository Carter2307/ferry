The kind is `service`. You can also write `svc`.

```bash title="Terminal"
ferry env set api 'SEARCH_URL=${{service.search.internalUrl}}/v1'
```

## The properties

| Property | Aliases | Value |
|---|---|---|
| `host` | `hostname` | The service name, its <Term id="hostname" /> on the <Term id="private-network" /> |
| `port` | | The port the service listens on |
| `hostport` | | `host:port`, for example `api:3000` |
| `internalUrl` | | `http://host:port` |
| `url` | `externalUrl` | The public URL (web services and static sites only) |

## The port must be known

`port`, `hostport` and `internalUrl` need the <Term id="port" /> of the target service. Ferry knows it after that service deployed, or when you set its port with `--port`.
