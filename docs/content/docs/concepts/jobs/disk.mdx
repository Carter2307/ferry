---
title: Jobs and the disk
description: A one-off job gets the disk of its service at the same path. It can read and write the same files.
---

When a service has a <Term id="disk" />, each <Term id="one-off-job" /> of that service can read and write the files of the service.

## Try it

<Terminal
  lines={[
    "$ ferry run files --follow -- 'ls -la /data'",
    "==> Mounting the service's disk at /data",
    '==> Running `ls -la /data`',
  ]}
/>

<Callout type="warning" title="Two programs write to one disk">
The job and the <Term id="instance" /> use the disk at the same time. Make sure that your command is safe next to the app.
</Callout>

[Persistent disks](/docs/concepts/scaling/disks) explains the disk of a service.
