A <Term id="job-run" /> is one <Term id="container" /> that runs one command, then stops. A run ends with one of three statuses: `succeeded` (<Term id="exit-code" /> 0), `failed` or `canceled`.

## The two kinds

| Kind | What starts a run | Example |
|---|---|---|
| <Term id="one-off-job">One-off job</Term> | You, with `ferry run`, on a deployed service | A database migration |
| <Term id="cron-job">Cron job</Term> | Its <Term id="cron-schedule" />. A cron job is a [type of service](/docs/concepts/services). | A command each day at 03:00 UTC |

## Run a job

```bash title="Terminal"
ferry run api --follow -- npm run migrate
```
