The <Term id="scheduler" /> starts the runs of each <Term id="cron-job" />. One cron job has one run at a time.

```text title="Log of the run in progress" noCopy
==> Warning: a scheduled run was skipped because this run is still running (for 48s); cancel it if it is stuck, or the schedule stays blocked
```

## What Ferry does not do

| Case | Result |
|---|---|
| The server was down at the time of a run. | Ferry skips the run. It does not do it later. |
| The cron job is suspended. | No run starts. |
| The cron job has no <Term id="live-deploy" />. | No run starts. |
| A run fails. | Ferry does not try again. |
| A run takes a long time. | Ferry sets no time limit. |

<Callout type="warning" title="A run that hangs blocks the schedule">
No new run starts until that run ends. [Cancel it](/docs/concepts/jobs/cancel).
</Callout>
