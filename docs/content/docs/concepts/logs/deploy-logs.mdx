A <Term id="deploy-log" /> starts when the deploy goes into the queue. It ends when the deploy is live, failed or canceled.

## Read a deploy log

```bash title="Terminal"
ferry deploy api --follow              # trigger a deploy and stream its log
ferry logs --deploy dep-285c0c8495fe459db551 -f
ferry logs --deploy dep-285c0c8495fe459db551 > deploy.log   # the stored log
```

If the deploy fails, `--follow` exits with code 1.

## The output of the new instances

While the new <Term id="instance">instances</Term> start, Ferry copies their output into the deploy log. The `[2fa90d]` line above is such a line.

If an instance crashes during the <Term id="health-check" />, Ferry copies its last 50 lines. Thus you see the cause in the same log.

See also [History and logs](/docs/concepts/deploys/history) of a deploy.
