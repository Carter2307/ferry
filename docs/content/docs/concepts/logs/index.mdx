A <Term id="log" /> is the text that a program writes while it runs. Ferry keeps three logs: the deploy log, the runtime log and the job log.

You can read each log when it is complete, or follow it live.

## Follow the log of a service

```bash title="Terminal"
ferry logs api -f
```
