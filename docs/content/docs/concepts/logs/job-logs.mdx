A <Term id="job-log" /> is the output of one <Term id="job-run" />. See [Jobs & cron](/docs/concepts/jobs).

## Read a job log

```bash title="Terminal"
ferry jobs nightly                                # find the run
ferry logs --job job-48dd0201159b41c3bb58 -f
ferry run api --follow -- npm run migrate         # start a job and stream it
```

## How long Ferry keeps it

Ferry keeps the logs of the newest runs of each service that are complete. The default is 100 runs.

Ferry deletes an older run together with its log.

| Flag of `ferryd` | Default |
|---|---|
| `--keep-job-runs` | 100 |
