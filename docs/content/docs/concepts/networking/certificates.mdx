## See the certificates

<Terminal
  lines={[
    '$ ferry certificates',
    'HOST               SERVICE   CERTIFICATE',
    'shop.example.com   shop      issued        expires in 2mo',
  ]}
/>

In the dashboard, open **Server → Domains**. The list has each <Term id="hostname" /> with the state of its <Term id="certificate" />.

| State | Meaning |
|---|---|
| Issued | The host has its certificate. Ferry shows the date when it ends. |
| In request | Ferry requests the certificate now. |
| Failed | The request failed. Ferry shows the cause and the time of the next try. |

<Accordions>
  <Accordion title="Before the certificate is there">
    A host with no certificate yet answers HTTPS with a <Term id="self-signed" />. Thus the <Term id="tls" /> handshake never fails hard.
  </Accordion>
  <Accordion title="Where Ferry keeps the certificates">
    The ACME account and the certificates are in `<data-dir>/certs`. The private keys have the mode `0600`. Ferry loads them again at startup.
  </Accordion>
</Accordions>
