Each <Term id="datastore" /> also publishes its <Term id="port" /> on the server: on `127.0.0.1`, with a port that Ferry chooses one time, when you create the datastore.

The external <Term id="connection-string" /> uses that port. Thus tools on the server itself can connect: `psql`, or a GUI through an <Term id="ssh-tunnel" />.

## Open a tunnel

```bash title="Terminal"
ssh -L 62975:127.0.0.1:62975 you@your-server   # then use the external URL on your machine
```

## The host in the connection string

`--advertise-host` changes only the host that Ferry prints in external connection strings. The default is `127.0.0.1`.

The port stays bound to `127.0.0.1`. Ferry never exposes a datastore on a public interface.

See [Datastores](/docs/concepts/datastores).
