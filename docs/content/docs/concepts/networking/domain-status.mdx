## The statuses

| Status | Meaning |
|---|---|
| `pending` | You connected the domain. Ferry verifies it each 15 seconds. |
| `active` | The test passed. Ferry serves each service under the domain. No deploy is necessary. |
| `misconfigured` | The <Term id="dns" /> of the domain broke, and three checks failed. Ferry continues to serve the domain. |

## See the status

```bash title="Terminal"
ferry domains
```

The command shows the status of each domain, and what its last verification found.

## Domains with no test

- Ferry always serves the <Term id="base-domain" />.
- Ferry never verifies a <Term id="local-name" />: `localhost`, `*.localhost`, `*.local`, `*.internal`, `*.test`.
