Each Ferry server runs one <Term id="proxy" />. The proxy receives all the public traffic and sends each request to a <Term id="container" /> of the correct <Term id="service" />.

Behind the proxy, all the containers of the server share a <Term id="private-network" />. There, they call each other by name.

## See your domains

```bash title="Terminal"
ferry domains        # the domains of the server and their status
ferry certificates   # each hostname and the state of its certificate
```
