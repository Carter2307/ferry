The <Term id="proxy" /> does these steps in this order. The first two steps apply only to two special paths.

## The host

The <Term id="host-header" /> gives the <Term id="hostname" /> that the client wants. This is how one proxy serves many services on one <Term id="ip-address" />.

When the proxy reads the host, it ignores:

- the case of the letters
- the port
- a dot at the end
