A <Term id="server-domain" /> is a name that Ferry serves your services under. Connect `example.com`: then each <Term id="web-service" /> and <Term id="static-site" /> also answers at `<name>.example.com`.

One <Term id="wildcard-record" /> (`*.example.com`) covers each service, present and future.

## Connect a domain

```bash title="Terminal"
ferry domains connect example.com   # prints the DNS record to create
ferry domains                       # status of each domain, and what its last verification found
```

In the <Term id="dashboard" />, use **Server → Domains**. For the complete procedure, follow [Connect a domain](/docs/guides/domains).

## The three names

| Name | Meaning |
|---|---|
| <Term id="base-domain">Base domain</Term> | The first domain of a server (`--base-domain`). Ferry always serves it. |
| Connected domain | A domain that you add. It starts as [`pending`](/docs/concepts/networking/domain-status). |
| <Term id="default-domain">Default domain</Term> | The domain that Ferry shows service URLs with: the dashboard, `ferry open`, `FERRY_EXTERNAL_URL`. |

<Accordions>
  <Accordion title="Change the default domain">
    If the default is a <Term id="local-name" />, the first domain that reaches the server becomes the default. To change it, use `ferry domains default`.
  </Accordion>
</Accordions>
