A <Term id="cpu-limit" /> is the most <Term id="cpu-core" /> time that one <Term id="container" /> can use. The default limit is 1 CPU.

At the limit, the kernel does not stop the container. It <Term id="throttle">throttles</Term> it.

## Write an amount

| You write | Ferry reads |
|---|---|
| `0.5` | Half a core |
| `2` | Two cores |
| `500m` | 500 <Term id="millicore">millicores</Term> (0.5) |

Ferry rounds an amount to 0.01 CPU. A limit can be from 0.01 to 512 CPUs.

## Set the limit

```bash title="Terminal"
ferry create api --repo https://github.com/you/api --memory 1G --cpu 0.5
ferry update api --cpu default         # back to the server default
```

<Callout type="warning" title="Small servers">
On a server with one CPU, the default limit of 1 CPU is the full server. Use a lower `--default-cpu-limit` there, for example `0.5`.
</Callout>
