A <Term id="resource-limit" /> is the most memory and CPU that one <Term id="container" /> can use. Ferry puts limits on each container that it starts: instances, one-off jobs, cron runs and datastores.

An app with a bug gets slower or stops. It cannot stop the server, `ferryd` or your databases.

## Set a limit

```bash title="Terminal"
ferry update api --memory 2G
ferry restart api --follow
```
