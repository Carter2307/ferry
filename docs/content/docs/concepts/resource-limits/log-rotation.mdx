<Term id="log-rotation">Log rotation</Term> keeps the log of a container small. The [runtime logs](/docs/concepts/logs/runtime-logs) go back only as far as these files.

## Change the rotation

| Flag of `ferryd` | Default | Meaning |
|---|---|---|
| `--log-max-size` | 10 MiB | The size at which Docker starts a new file |
| `--log-max-files` | 3 | The number of files, with the current file |

`--log-max-size 0` tells Ferry not to change the log settings of Docker.

<Accordions>
  <Accordion title="Other log drivers">
    Ferry sets the rotation only when the default <Term id="log-driver" /> of Docker is `json-file`. This is the default of Docker.

    If you set up Docker with a different driver (journald, syslog, fluentd, `local`…), Ferry keeps it. That driver has its own limits. Then `ferryd` prints `Docker's journald log driver (kept)` when it starts.
  </Accordion>
</Accordions>
