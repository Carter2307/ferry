A <Term id="memory-limit" /> is a box around a <Term id="container" />. The container cannot grow out of it. The default limit is 512 <Term id="mib" />.

When the app needs more, the <Term id="kernel" /> stops its process. This is an <Term id="oom" />. The container gets no <Term id="swap" /> above the limit.

Docker starts an instance or a datastore again. A job run fails.

## Write a size

| You write | Ferry reads |
|---|---|
| `512` | 512 MiB. A number with no unit is MiB. |
| `512M` | 512 MiB |
| `1G` | 1 GiB |
| `1.5G` | 1.5 GiB |
| `2GiB` | 2 GiB |

`M`, `MB` and `MiB` all mean MiB. `G`, `GB` and `GiB` all mean GiB. Docker reads sizes the same way.

A limit can be from 16 MiB to 1 TiB.

## Set the limit

```bash title="Terminal"
ferry update api --memory 2G
ferry restart api
```

See [Set the limits of a service](/docs/concepts/resource-limits/service) and [Out-of-memory kills](/docs/concepts/resource-limits/oom-kills).
