The <Term id="pids-limit" /> counts the <Term id="os-process">processes</Term> and the <Term id="thread">threads</Term> of one container together. The default is 1024.

At the limit, <Term id="fork" /> fails in the container. A <Term id="fork-bomb" /> stops there.

## Change the limit

| Flag of `ferryd` | Default | Off |
|---|---|---|
| `--pids-limit` | 1024 | `--pids-limit 0` |

Some apps run thousands of threads. For them, start `ferryd` with a higher `--pids-limit`.

See [Server defaults](/docs/concepts/resource-limits/defaults).
