<Term id="maxmemory" /> is a setting of Redis. With it, a full Redis refuses writes. Without it, the kernel stops Redis at the memory limit.

Redis uses the other quarter to save its append-only file and for the buffers of clients.

## Change it

Change the memory limit of the datastore. Ferry sets `maxmemory` again.

```bash title="Terminal"
ferry db create cache --kind redis --memory 256M
ferry db update cache --memory 512M
```

<Accordions>
  <Accordion title="When Ferry sets maxmemory">
    - When Redis starts.
    - When you change the memory limit.

    A Redis with no memory limit gets no `maxmemory`.
  </Accordion>
</Accordions>
