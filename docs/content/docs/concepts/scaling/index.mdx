These operations change what runs. They build nothing new. A scale, a suspend and a resume start or stop <Term id="container">containers</Term> of the <Term id="live-deploy" />. A <Term id="restart" /> is a new deploy of the live image with the current settings.

## The four operations

| Operation | Command | New deploy? | Downtime |
|---|---|---|---|
| [Scale](/docs/concepts/scaling/scale) | `ferry scale NAME N` | No | None |
| [Suspend](/docs/concepts/scaling/suspend) | `ferry suspend NAME` | No | Yes: the proxy answers `503` |
| [Resume](/docs/concepts/scaling/resume) | `ferry resume NAME` | No | Until the instances accept connections |
| [Restart](/docs/concepts/scaling/restart) | `ferry restart NAME` | Yes (trigger `restart`), with the live image | None, but for a service with a disk |

## Scale a service

```bash title="Terminal"
ferry scale api 3
```
