An <Term id="instance" /> is one container of a service. All the instances of a service do the same work.

The <Term id="proxy" /> shares the requests of a <Term id="web-service" /> or a <Term id="static-site" />. The rule is <Term id="round-robin" />: each instance gets a request in turn.

On the <Term id="private-network" />, the name of the service gives the addresses of all its instances. See [Networking](/docs/concepts/networking).

## The limits are for each instance

Each instance has the memory and CPU limits of the service: 512 MiB and 1 CPU, unless you set other values. Thus 3 instances can use 3 times the limit.

`ferry status` shows the use of each instance. See [Resource limits](/docs/concepts/resource-limits).

<Callout type="info" title="Manual scaling only">
Ferry has no <Term id="autoscaling" />. You choose the number of instances.
</Callout>
