---
title: Resume a service
description: A resume starts the instances of the live deploy again. There is no new deploy and no build.
---

```bash title="Terminal"
ferry resume api
```

To <Term id="resume" /> a service is to start its <Term id="instance">instances</Term> again from the <Term id="live-deploy" />. Ferry builds nothing.

## If the image is gone

If the <Term id="image" /> of the live deploy does not exist now, Ferry refuses the resume. Then do a manual deploy with `ferry deploy NAME` or `ferry up`.

```bash title="Terminal"
ferry deploy api
```

The manual deploy deploys the service. It resumes the service when the deploy is live.
