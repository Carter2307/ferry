To <Term id="suspend" /> a service is to stop it and keep all that it has. The settings, the variables, the deploys and the data on the <Term id="disk" /> stay.

## While the service is suspended

| What | Result |
|---|---|
| A request to the service | The <Term id="proxy" /> answers `503`. |
| The schedule of a <Term id="cron-job" /> | No run starts. |
| A push to GitHub, or a <Term id="blueprint" /> | No deploy starts. |
| The [deploy hook](/docs/concepts/deploys/deploy-hooks) | It answers `409`. |
| `ferry deploy` | Ferry refuses. Resume the service first. |

## Start it again

```bash title="Terminal"
ferry resume api
```

See [Resume a service](/docs/concepts/scaling/resume).
