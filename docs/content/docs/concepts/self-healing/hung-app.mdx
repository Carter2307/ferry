Ferry uses the path of the <Term id="health-check" /> (`--health`) only while a deploy starts new instances. After that, the <Term id="proxy" /> tests only the <Term id="tcp" />.

An app that hangs with an open port keeps its traffic. Ferry does not see the problem.

## What to do

Make your app exit when it cannot serve. Docker then restarts the container, as for each crash.

To see the restarts of each instance, use this command:

```bash title="Terminal"
ferry status api
```

See [Health checks](/docs/concepts/deploys/health-checks) and [When a container crashes](/docs/concepts/self-healing/crash).
