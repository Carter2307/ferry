Ferry keeps the <Term id="desired-state" /> in its <Term id="sqlite" /> database: services, live deploys, numbers of instances and datastores. The <Term id="reconciler" /> compares it with the <Term id="actual-state" /> in Docker.

You do not restart a crashed app. You do not remove old containers.

## See the state of a service

```bash title="Terminal"
ferry status api
```
