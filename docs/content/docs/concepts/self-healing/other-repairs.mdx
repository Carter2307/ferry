## What each pass repairs

| Thing | Repair |
|---|---|
| <Term id="datastore" /> | If its container stopped, Ferry restarts it. If the container disappeared, Ferry creates it again. The volume keeps the data. |
| Failed datastore | Ferry tries again, with a longer wait after each failure. |
| <Term id="orphan" /> | Ferry removes a container of this server whose service or datastore does not exist. It also removes old job containers. |
| <Term id="proxy-route" /> | Ferry removes the routes of deleted services. |

See [Datastores](/docs/concepts/datastores).

## Between two passes

The <Term id="route-watcher" /> lists the instances that run, each second. If Docker restarts a container on a new port, the route follows in about one second.

```bash title="Terminal"
ferry status api
```

The command shows the port of each instance.
