A <Term id="worker" /> does work that no request waits for. Examples are queue consumers, bots and stream processors.

Ferry does not give a `PORT` variable to a worker.

## When a worker is healthy

A new <Term id="instance" /> is healthy when it runs for 5 seconds after its start. See [Health checks](/docs/concepts/deploys/health-checks).

## Create a worker

```bash title="Terminal"
ferry create mailer --type worker --repo https://github.com/you/app --start-cmd "node worker.js"
```

`--start-cmd` is the command that starts the process. See [Start command](/docs/concepts/builds/start-command).
