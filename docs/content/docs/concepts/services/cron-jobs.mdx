A <Term id="cron-job" /> has no instance that runs all the time. Each run is a new <Term id="container" />.

## Create a cron job

```bash title="Terminal"
ferry create nightly --type cron --image busybox:stable --schedule "0 3 * * *" --start-cmd 'echo hello'
ferry run nightly --follow
```

`ferry run <name>` starts a run immediately.

## The schedule

The <Term id="cron-schedule" /> is a <Term id="cron-expression" /> of 5 fields: `minute hour day-of-month month day-of-week`. An alias such as `@daily` or `@hourly` is also correct.

<Callout type="warning" title="The schedule is in UTC">
Ferry reads the schedule in <Term id="utc" />, not in your local time.
</Callout>
