## Create a service from an image

```bash title="Terminal"
ferry create hello --image nginx:alpine --port 80
```

The <Term id="image" /> comes from a <Term id="registry" />. The <Term id="runtime" /> of the service becomes `image`.

## When Ferry pulls the image

| <Term id="image-tag">Tag</Term> of the image | Ferry pulls it |
|---|---|
| No tag, or `:latest` | At each deploy |
| Each other tag | Only when the image is not on the server |

## The pinned image

A <Term id="pinned-image" /> is the exact image that one deploy pulled. Restarts, crash replacements and rollbacks run that image.

<Callout type="warning" title="Public images only">
Ferry has no registry authentication.
</Callout>
