A <Term id="service" /> is one app that Ferry builds and runs as one or more Docker <Term id="container">containers</Term>.

Each service has a name, a type, a <Term id="source" />, settings and <Term id="env-var">environment variables</Term>. The name is unique. A [deploy](/docs/concepts/deploys) puts the code into the containers.

## Create a service

```bash title="Terminal"
ferry create api --repo https://github.com/you/api --branch main
```

This command makes a <Term id="web-service" /> from a git <Term id="repository" />, then deploys it.
