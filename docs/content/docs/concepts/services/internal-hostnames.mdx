Each service is on the <Term id="private-network" /> with its own name. Each <Term id="datastore" /> is there with the name of the datastore.

## Call another service

From each service or <Term id="job" />, another service is at `<name>:<port>`.

```bash title="From inside a container"
curl http://api:3000/health
```

## Find the port

The port is the container port of the service that you call. `ferry show api` prints it as **Internal address**.

The <Term id="reference" /> `${{service.api.hostport}}` gives the <Term id="internal-address" />. Thus you do not write the port in your code.

```bash title="Terminal"
ferry env set web 'API_URL=http://${{service.api.hostport}}'
```
