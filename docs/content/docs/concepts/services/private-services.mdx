A <Term id="private-service" /> is like a web service, but it has no <Term id="public-url" />. Other services and jobs call it on the <Term id="private-network" /> at `<name>:<port>`. See [Internal hostnames](/docs/concepts/services/internal-hostnames).

## When to use it

- For an internal API.
- For an app that speaks <Term id="tcp">TCP</Term> and not HTTP.

A private service cannot have a <Term id="custom-domain" />.

## Create a private service

```bash title="Terminal"
ferry create search --type pserv --image getmeili/meilisearch:v1.10 --port 7700
```
