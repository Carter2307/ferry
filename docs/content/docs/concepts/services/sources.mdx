## How Ferry finds the source

A <Term id="source" /> is a git <Term id="repository" />, a Docker <Term id="image" /> or an <Term id="upload" />. Ferry reads it from the settings of the service.

| The service has | Source |
|---|---|
| An image | [A Docker image](/docs/concepts/services/docker-image) |
| A repository and no image | [A git repository](/docs/concepts/services/git-repository) |
| No image and no repository | [An upload](/docs/concepts/services/upload) |

## Change the source

Set the new source. Clear the old source in the same command.

```bash title="Terminal"
ferry update api --image ghcr.io/you/api:1.4 --repo ""
```

Thus Ferry never forgets a repository or an image by accident.
