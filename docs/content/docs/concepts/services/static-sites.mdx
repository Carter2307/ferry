A <Term id="static-site" /> is files that <Term id="nginx" /> serves behind the <Term id="proxy" />. A build step before that is optional: `npm run build`, Hugo, MkDocs, Jekyll…

Ferry makes the <Term id="image" />: an `nginx:alpine` server that listens on port 80.

## Create a static site

```bash title="Terminal"
ferry up my-site --type static --dir ./public
```

## How nginx finds a page

For `/about`, nginx serves `about.html` or `about/index.html`.

For the exact rules, the build step and the publish directory, see [Static sites](/docs/concepts/builds/static-sites) in Builds.
