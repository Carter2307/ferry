A <Term id="web-service" /> is a public HTTP app. The <Term id="proxy" /> gives the requests to its <Term id="instance">instances</Term> in turn. This is <Term id="load-balancing" />.

The proxy sends `<name>.<domain>` to the service, for each domain of the server. It also sends each [custom domain](/docs/concepts/networking) of the service to it.

HTTP/1.1, <Term id="http2" /> and <Term id="websocket">WebSockets</Term> pass through the proxy.

## Create a web service

```bash title="Terminal"
ferry create api --repo https://github.com/you/api --health /healthz --instances 2
```

`--health` sets the path of the [health check](/docs/concepts/deploys/health-checks). `--instances` sets the number of instances.

## What your app must do

Your app must listen on the <Term id="port" /> in the `PORT` environment variable, on the address `0.0.0.0`.

<Callout type="warning">
An app that listens on `127.0.0.1` in its container gets no traffic.
</Callout>
