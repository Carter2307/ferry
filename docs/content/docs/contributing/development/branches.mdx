## Start a branch

New features start from `dev`. Give the <Term id="branch" /> the name of the change. Then <Term id="merge" /> it back into `dev`.

```bash title="Terminal"
git switch dev && git pull
git switch -c feat/my-feature
```

## Write the commit message

Start with the area that the <Term id="commit" /> changes: the crate name, `web` or `docs`. Then write a short summary.

```text title="Examples" noCopy
ferry-api: SSE change feed, embedded web client, job cancel
web: blue primary color
ferry-engine: fix verified findings
```

If the commit has more than one change, list the changes as bullets in the body.
