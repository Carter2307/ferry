<Steps>
<Step>

### Build the dashboard (optional)

```bash title="Terminal"
cd web && npm ci && npm run build && cd ..
```

`ferry-api` embeds `web/dist` when it compiles.

</Step>
<Step>

### Build the programs

```bash title="Terminal"
cargo build
```

<Term id="cargo" /> makes a <Term id="debug-build" />: `target/debug/ferryd` and `target/debug/ferry`.

</Step>
</Steps>

Then [start the server](/docs/contributing/development/run).

## A release build

```bash title="Terminal"
cargo build --release
```

A <Term id="release-build" /> puts the programs in `target/release/`.

<Accordions>
  <Accordion title="If you do not build the dashboard">
    The server works without `web/dist`. The page at `/` then explains how to build the dashboard.

    To work on the dashboard itself, see [Web client](/docs/contributing/web-client).
  </Accordion>
</Accordions>
