<Steps>
<Step>

### Point the CLI at the server

```bash title="Terminal"
export FERRY_SERVER=http://127.0.0.1:7878
export FERRY_TOKEN="$(cat ferry-data/api_token)"
```

The two variables do not change the config that `ferry login` saved for your usual server.

</Step>
<Step>

### Deploy the example

```bash title="Terminal"
cd examples/node-hello
../../target/debug/ferry up --follow
```

`--follow` shows the log until the <Term id="deploy" /> is live.

</Step>
<Step>

### Call the app

```bash title="Terminal"
curl http://node-hello.localhost:8080
```

The app answers with a line that starts with `Hello from Ferry (node)!`.

</Step>
</Steps>
