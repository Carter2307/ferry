Ferry is a Rust <Term id="workspace" /> with two front-end projects next to it: the <Term id="dashboard" /> in `web/` and this site in `docs/`.

Each <Term id="crate" /> has <Term id="unit-test">unit tests</Term> next to its code and <Term id="integration-test">integration tests</Term> in `crates/<crate>/tests/`. [The crates](/docs/architecture/overview/crates) shows how they depend on each other.

Read `DESIGN.md` before you change a behavior. It is the contract between the crates.

## Build and start

```bash title="Terminal"
cargo build
./target/debug/ferryd run --data-dir ./ferry-data
```
