## The tools

| Tool | Version | Use |
|---|---|---|
| <Term id="rust" /> | 1.89 or newer (edition 2024) | `ferryd`, `ferry` and each <Term id="crate" /> |
| <Term id="docker" /> | <Term id="docker-desktop" /> on macOS works | To run `ferryd` and the <Term id="e2e-test">end-to-end tests</Term> |
| `git` and `docker` CLIs | On the <Term id="path-variable" /> | Builds: `ferry-build` runs them |
| <Term id="nodejs" /> | 20.19 or newer, with <Term id="npm" /> | The dashboard (`web/`) and the docs (`docs/`) |

Then [build Ferry](/docs/contributing/development/build).
