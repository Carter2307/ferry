## What the server prints

`ferryd` prints the URL of the <Term id="api" />. While the server has no <Term id="admin-account" />, it also prints the `Create your account` link.

Open the link one time. It creates the account that you use to sign in to the dashboard.

## The data directory

`./ferry-data` is the default <Term id="data-directory" />. git ignores it.

| File | Use |
|---|---|
| `ferry-data/api_token` | The <Term id="server-token" />, for the commands of [the next page](/docs/contributing/development/deploy) |
| `ferry-data/ferryd.log` | The log of a server in the <Term id="background" />. Read it with `ferryd logs -f`. |

## More detail in the log

Set the variable `RUST_LOG` before you start the server. The default level is `info`.

| Value | Result |
|---|---|
| `RUST_LOG=debug` | More detail from each crate |
| `RUST_LOG=ferry_engine=debug` | A filter: more detail from one crate |
