## The flags

```bash title="Terminal"
./target/debug/ferryd run \
  --data-dir ./dev-data \
  --name-prefix ferrydev \
  --api-addr 127.0.0.1:17878 \
  --proxy-addr 127.0.0.1:18080
```

| Flag | The development server gets |
|---|---|
| `--data-dir ./dev-data` | Its own <Term id="data-directory" /> |
| `--name-prefix ferrydev` | Its own <Term id="name-prefix" /> for the Docker names |
| `--api-addr 127.0.0.1:17878` | Its own address for the API |
| `--proxy-addr 127.0.0.1:18080` | Its own address for the <Term id="proxy" /> |

## Why it is safe

`ferryd` refuses to start on a prefix that another data directory owns. This protects the containers of the other server.

[Multiple servers](/docs/guides/multiple-servers) gives the full rules.
