The site uses the <Term id="design-token">design tokens</Term> of the dashboard. See [Design tokens](/docs/contributing/web-client/design-tokens).

Because of this import, the root of the Next.js <Term id="bundler" /> is the repository, not `docs/`.

## Classes for custom UI

| Class | Use |
|---|---|
| `bg-surface-100`, `text-foreground-light`, `border-border-strong`, `text-primary`, `mono-label`… | The token utilities |
| `rounded-[var(--ferry-radius-md)]` | Controls |
| `rounded-[var(--ferry-radius-lg)]` | Cards |

## Change a color

Change colors only in `tokens.css`. Then build the dashboard and the docs again.
