<Steps>
<Step>

### Install the packages

```bash title="Terminal"
cd docs
npm install
```

</Step>
<Step>

### Start the dev server

```bash title="Terminal"
npm run dev                    # → http://localhost:3000
```

</Step>
<Step>

### Open the site

Open `http://localhost:3000` in your browser.

</Step>
</Steps>

## If port 3000 is in use

```bash title="Terminal"
npm run dev -- --port 3210     # when port 3000 is taken
```
