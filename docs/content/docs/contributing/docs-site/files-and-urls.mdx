## Pages

A page is an <Term id="mdx" /> file in `content/docs/`. The URL follows the path.

A subject with more than one idea is a folder. Its `index.mdx` keeps the URL of the subject.

## The sidebar

Each folder has a `meta.json` file:

```json title="content/docs/concepts/deploys/meta.json"
{
  "title": "Deploys",
  "icon": "CloudUpload",
  "pages": ["steps", "triggers", "deploy-hooks"]
}
```

| Key | Use |
|---|---|
| `title` | The name of the folder in the sidebar |
| `icon` | The icon of the folder |
| `pages` | The pages, in order |

- A top-level folder is a section of the sidebar.
- If a page is not in `pages`, the build makes it but the sidebar does not list it.
