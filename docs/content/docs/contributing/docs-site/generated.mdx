<Callout type="warning" title="Never edit these files by hand">
The script writes them again and your change goes away. To change them, see [Change a reference page](/docs/contributing/docs-site/regenerate).
</Callout>

## The four files

| File | Source |
|---|---|
| `openapi/ferry.json` | `cargo run -p ferryd -- --dump-openapi`, with no change |
| `content/docs/reference/api/*` | fumadocs-openapi: one page per <Term id="openapi">OpenAPI</Term> tag, plus `index.mdx` and `meta.json` |
| `content/docs/reference/cli.mdx` | `cargo run -p ferry-cli -- markdown-help` (clap-markdown) |
| `content/docs/reference/server-options.mdx` | `cargo run -p ferryd -- --dump-markdown-help`, plus the environment variables from `ferryd --help` |

<Accordions>
  <Accordion title="Why the API pages have no playground">
    The API pages have no "try it" playground. `ferryd` sends no <Term id="cors" /> headers. Thus a browser cannot call it from the origin of the docs.

    Each server serves its own <Term id="swagger-ui" /> at `/api/docs` for that.
  </Accordion>
</Accordions>
