This site is in `docs/`. It is a project of its own, like the dashboard in `web/`.

It uses <Term id="fumadocs" /> on <Term id="nextjs" /> 16 (App Router, React 19, TypeScript strict, Tailwind CSS v4). The build makes a <Term id="static-export" /> in `docs/out/`.

## Start the dev server

```bash title="Terminal"
cd docs
npm install
npm run dev                    # → http://localhost:3000
```
