<Steps>
<Step>

### Rust

```bash title="Terminal"
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

If your change touches Docker, builds, the proxy or the engine, also run `FERRY_E2E=1 cargo test` for the crates that you changed.

</Step>
<Step>

### Dashboard

If `web/` changed, run these commands in `web/`:

```bash title="Terminal"
npm test
npm run typecheck
npm run lint
npm run build
```

</Step>
<Step>

### Docs

If a command, a flag, a route or a <Term id="dto" /> changed, run these commands in `docs/`:

```bash title="Terminal"
npm run generate
npm run build
```

</Step>
</Steps>

<Callout type="warning" title="If tokens.css changed">
The dashboard and the docs share `web/src/styles/tokens.css`. Build the two projects again.
</Callout>
