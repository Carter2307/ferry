## Run the checks

```bash title="Terminal"
cd docs
npm run typecheck
npm run build            # static export, then a check of every internal link and anchor
npm run generate:check   # fails when a generated reference page is stale (needs cargo)
```

`npm run generate:check` needs <Term id="cargo" />. The other two commands need only <Term id="nodejs" />.

See [Docs site](/docs/contributing/docs-site). [Generated references](/docs/contributing/docs-site/generated) explains the stale pages.
