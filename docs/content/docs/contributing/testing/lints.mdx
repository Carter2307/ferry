## Run the two commands

```bash title="Terminal"
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
```

| Part of the command | Effect |
|---|---|
| `--check` | The <Term id="formatter" /> only reports a difference. |
| `-D warnings` | Each warning of a <Term id="lint" /> stops the command with an error. |

The two commands must pass. See the [coding rules](/docs/contributing/development/coding-rules).
