## Run the checks

```bash title="Terminal"
cd web
npm test              # Vitest: SSE parser, change feed, log helpers, formatting, .env parsing, resource limits
npm run typecheck
npm run lint
npm run build
```

## Where the tests are

The tests are next to the code: `src/**/*.test.ts` and `src/**/*.test.tsx`. Vitest finds these files.
