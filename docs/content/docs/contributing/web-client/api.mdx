The dashboard uses only the public REST <Term id="api" />, like the CLI. See the [API overview](/docs/reference/api-overview).

## The rules of a request

| Subject | Rule |
|---|---|
| Format | A <Term id="data-query" /> or a <Term id="mutation" /> is a JSON call to `/api/v1/*`. |
| Origin | The call goes to the same <Term id="origin" />. Thus <Term id="cors" /> is not necessary. |
| Proof | The browser sends the <Term id="session-cookie" /> by itself. The app sets no `Authorization` header. |
| Errors | `src/lib/api/client.ts` wraps `fetch`. It changes an error body into `ApiError { status, code, message }`. |

[Sign-in and the session](/docs/contributing/web-client/sign-in) describes the cookie. [Live updates](/docs/contributing/web-client/live-updates) describes the streams.
