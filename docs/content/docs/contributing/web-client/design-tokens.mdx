A <Term id="design-token" /> is a value of the design with a name. The file is `web/src/styles/tokens.css`.

The tokens are plain <Term id="css-custom-property">CSS custom properties</Term>:

| Selector | Values |
|---|---|
| `:root` | The light values |
| `.dark` | The dark values |

<Callout type="warning" title="Change colors in tokens.css only">
The two projects depend on this file. After a change, run the commands below.
</Callout>

## After a change

```bash title="In web/"
npm run typecheck
npm run build
npm test
```

```bash title="In docs/"
npm run build
```
