<Steps>
<Step>

### Start a server

Run `ferryd` as in [Start the server](/docs/contributing/development/run).

The <Term id="dev-server" /> needs only the API of `ferryd`. The dashboard that `ferryd` embeds does not matter.

</Step>
<Step>

### Start Vite

```bash title="Terminal"
cd web
npm install
FERRY_API_URL=http://127.0.0.1:7878 npm run dev    # → http://localhost:5173
```

<Term id="vite" /> serves the app with <Term id="hmr" />. [The dev proxy](/docs/contributing/web-client/dev-proxy) sends the API calls to `FERRY_API_URL`.

</Step>
<Step>

### Sign in

Open `http://localhost:5173`. Sign in with the email and the password of the <Term id="admin-account" /> of the server.

</Step>
</Steps>

  <Accordion title="A server with no account">
