## Where each request goes

| Path | Goes to |
|---|---|
| `/api`, `/hooks`, `/healthz` | `FERRY_API_URL`. The default is `http://127.0.0.1:7878`. |
| Each other path | The app, from Vite |

## What the proxy keeps

- **The host.** The proxy sends the host that the browser used in the <Term id="header" /> `X-Forwarded-Host`. `ferryd` compares it with the `Origin` of each request that has the <Term id="session-cookie" />.
- **The streams.** <Term id="sse" /> pass through the proxy with no buffer and no compression. The log streams and the <Term id="change-feed" /> use them.

`npm run preview` uses the same proxy on port 4173.
