The <Term id="dashboard" /> is a <Term id="spa" /> in `web/`, with its own toolchain. `ferryd` serves it at `/`.

The Rust build never runs Node. `ferry-api` embeds what `web/dist` contains when it compiles.

## Start the dev server

```bash title="Terminal"
FERRY_API_URL=http://127.0.0.1:7878 npm run dev    # → http://localhost:5173
```
