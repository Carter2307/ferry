## The folders

<Files>
  <Folder name="web/src" defaultOpen>
    <File name="main.tsx, App.tsx (providers), routes.tsx, RequireAuth.tsx" />
    <File name="styles/tokens.css — design tokens shared with the docs" />
    <File name="styles/globals.css — tokens mapped to shadcn variables" />
    <Folder name="lib" defaultOpen>
      <File name="api/ — client, types, endpoints, keys, sse, events, queries, useLogStream" />
      <File name="format.ts, dotenv.ts, logs.ts — pure helpers with tests" />
    </Folder>
    <File name="stores/ — auth.ts, ui.ts (Zustand)" />
    <File name="components/ui/ — shadcn primitives (customized)" />
    <File name="components/shell/ — AppShell, TopBar, IconRail, InnerMenu, CommandMenu, ConnectPopover" />
    <File name="components/patterns/ — PageHeader, FormCard, InfoTile, MetricCard, EmptyState, LogViewer…" />
    <File name="pages/ — routed pages, one named XxxPage export per file" />
  </Folder>
</Files>

Each file in `pages/` has one named export, for example `LoginPage`. `routes.tsx` gives a URL to each page.
