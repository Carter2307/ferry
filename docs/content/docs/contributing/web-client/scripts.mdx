## What each script does

Run each script in `web/`.

| Script | What it does |
|---|---|
| `npm run dev` | <Term id="vite" /> dev server with <Term id="hmr">HMR</Term> and the API proxy (port 5173) |
| `npm run build` | `tsc -b && vite build` → `dist/`, with hashed files under `dist/assets/` |
| `npm run preview` | Serves `dist/` with the same proxy (port 4173) |
| `npm test` | <Term id="vitest" /> unit tests (`src/**/*.test.ts` and `src/**/*.test.tsx`) |
| `npm run typecheck` | `tsc -b --noEmit` |
| `npm run lint` | <Term id="eslint" /> (typescript-eslint, react-hooks, react-refresh) |

A hashed file has a code in its name. The code changes when the content changes.
