## The rules

`ferryd` serves the app at `/`.

| Request | Answer |
|---|---|
| A file under `/assets/` | The file, with `Cache-Control: public, max-age=31536000, immutable` |
| Each other file, `index.html` first | The file, with `no-cache` and an <Term id="etag" /> |
| Another `GET` outside `/api`, `/hooks` and `/healthz` that is not a file | `index.html`. Thus a <Term id="history-url" /> such as `/services/api/logs` works after a reload. |
| A file under `/assets/` that does not exist | `404` |

<Term id="cache-control" /> tells the browser how long it can keep a file. `max-age=31536000` is one year, in seconds.
