## The parts

| Part | Tools |
|---|---|
| UI | <Term id="react" /> 19, <Term id="typescript" /> (strict), <Term id="shadcn" /> (Radix primitives, customized in `src/components/ui`), <Term id="lucide" /> icons |
| Style | <Term id="tailwind" /> v4, the Ferry <Term id="design-token">design tokens</Term> in `src/styles/tokens.css`, light and dark themes |
| Server state | <Term id="tanstack-query" /> v5 (`src/lib/api/queries/*`) |
| Client state | <Term id="zustand" /> (`src/stores/auth.ts`, `src/stores/ui.ts`) |
| Routing | <Term id="react-router" /> v7 with <Term id="history-url">history URLs</Term> and code-split pages |
| Build and tests | <Term id="vite" />, <Term id="vitest" /> |

A code-split page is a result of <Term id="code-splitting" />: the browser loads its file only when you open the page.
