## No secret in localStorage

The app keeps no token and no secret in <Term id="local-storage" />. The session is the <Term id="session-cookie" />, and the page cannot read it.

The app stores only the preferences of the UI, under the key `ferry.ui`:

- the theme
- the rail
- the options of the log viewer

## The theme before the first paint

`public/theme-init.js` applies the saved theme before the first paint.

It is an external file, not a script in the HTML. Thus the app works with a strict <Term id="csp" />: `script-src 'self'`.
