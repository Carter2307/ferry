Run [`ferry info`](/docs/reference/cli#ferry-info) at each time that you want to test the connection.

If the command prints these lines, the server URL and the <Term id="api-token" /> are good.

## What ferry login tests

`ferry login` calls `GET /api/v1/info` with the token before it saves the login.

Thus a bad URL or a bad token fails immediately. `ferry login` saves nothing.

## If it fails

The error tells you what to do. See [Exit codes and errors](/docs/getting-started/cli/exit-codes).
