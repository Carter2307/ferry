## Do it

<Steps>
<Step>

### Create an API token

In the dashboard, open **Server → Account → API tokens**. Click **New token**. Give a name such as `CI`, and an expiry.

The dashboard shows the token one time.

</Step>
<Step>

### Keep the token in your CI secrets

The script gets the token from the secrets. Do not write the token in the script.

</Step>
<Step>

### Set the two variables in the script

```bash title="deploy.sh"
export FERRY_SERVER=https://ferry.apps.example.com
export FERRY_TOKEN="$FERRY_API_TOKEN"   # from your CI secrets

ferry deploy api --follow   # exits with 1 if the deploy fails
```

The two variables win over the config file.

</Step>
</Steps>

<Callout type="warning" title="The token has full access">
The token can do all that the <Term id="cli" /> does. You can revoke it at each time under **Server → Account**.
</Callout>

  <Accordion title="A job that only starts a deploy">

  </Accordion>
