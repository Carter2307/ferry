## The commands that ask

`ferry delete`, `ferry db rm`, `ferry env-group rm` and `ferry deploy-hook rotate`.

```text title="The question" noCopy
Delete service 'node-hello' with all its deploys? [y/N]
```

## No question

Add `--yes`, or its short form `-y`.

## In a script or a CI job

If the input is not a terminal, these commands refuse to run without `--yes`.

```text title="Error" noCopy
error: refusing to delete service 'node-hello' with all its deploys without confirmation: re-run with --yes
```
