## Do it

```bash title="Terminal"
ferry deploy api --follow
```

`-f` is the short form of `--follow`. These commands start a deploy or a job, and accept `--follow`:

`ferry up`, `create`, `deploy`, `restart`, `rollback`, `env set`, `run`.

## The exit code

| <Term id="exit-code">Exit code</Term> | Meaning |
|---|---|
| `0` | The deploy went live, or the job is a success. |
| `1` | The deploy or the job failed, or a person canceled it. |

## Stop the follow

Press <kbd>Ctrl</kbd>+<kbd>C</kbd>. The deploy or the job continues on the server. `ferry` tells you how to see the log again:

```text title="Output" noCopy
Stopped following; the deploy continues on the server. Resume with: ferry logs --deploy dep-3493c505ea9b4415b359 -f
```
