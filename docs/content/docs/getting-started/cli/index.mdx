`ferry` is the <Term id="cli" /> of Ferry. Each command is a request to the <Term id="api" /> of <Term id="ferryd" />.

Thus the CLI works on the server, on your laptop or in a <Term id="ci" /> job. It only needs to reach the API through HTTP.

## Connect it to your server

```bash title="Terminal"
ferry login --server http://127.0.0.1:7878
```

The [CLI reference](/docs/reference/cli) lists each command and each option. To deploy your first app, read the [Quickstart](/docs/getting-started/quickstart).
