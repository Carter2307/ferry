## Do it

<Steps>
<Step>

### Build the binaries

Run <Term id="cargo" /> in the Ferry repository. [Installation](/docs/getting-started/installation) tells you what the build needs.

```bash title="Terminal"
cargo build --release
```

</Step>
<Step>

### Install `ferry`

```bash title="Terminal"
sudo install -m 0755 target/release/ferry /usr/local/bin/
```

</Step>
<Step>

### Make sure that it works

```bash title="Terminal"
ferry --version
```

The command prints the version of the CLI.

</Step>
</Steps>

## On another machine

`ferry` is one <Term id="binary" />. It has no runtime dependencies.

Copy the file to each machine that must control Ferry. Then [log in](/docs/getting-started/cli/login).
