## The two channels

| Channel | What `ferry` writes |
|---|---|
| <Term id="stdout" /> | The results. |
| <Term id="stderr" /> | The progress (`Packing …`, `Uploading …`), the warnings and the errors. |

## What the text looks like

`ferry` prints tables with aligned columns, and blocks of keys and values. See an example in [The commands that you use most](/docs/getting-started/cli/commands).

| Text | Form |
|---|---|
| A log line | `HH:MM:SS [instance] line` |
| A message from Ferry in a deploy log | It starts with `==>` |

For a script, use [JSON output](/docs/getting-started/cli/json).

  <Accordion title="Colors">
    `ferry` uses colors only when these three conditions are true:

    - The output is a terminal.
    - `NO_COLOR` has no value.
    - `TERM` is not `dumb`.
