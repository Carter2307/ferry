A <Term id="reference" /> is a value in the form `${{…}}`. It points to a datastore or to a service.

Your <Term id="shell" /> also uses `$` and `{`. Thus it tries to expand the reference.

## Do it

Put the full `KEY=value` text in single quotes.

```bash title="Terminal"
ferry env set api 'DATABASE_URL=${{datastore.app-db.connectionString}}'
```

See [Environment & env groups](/docs/concepts/environment) and [Env var references](/docs/reference/env-references).
