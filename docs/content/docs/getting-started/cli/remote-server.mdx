## Do it

<Steps>
<Step>

### Open the tunnel

```bash title="Terminal"
ssh -N -L 7878:127.0.0.1:7878 you@your-server &
```

The <Term id="ssh-tunnel" /> stays open in the background.

</Step>
<Step>

### Log in to the local address

```bash title="Terminal"
ferry login --server http://127.0.0.1:7878
```

The approval page opens through the same tunnel. Its address in your browser is `http://127.0.0.1:7878`.

</Step>
</Steps>

## With HTTPS and no tunnel

It is possible to put the dashboard on the proxy with <Term id="https" /> (`--dashboard-host`). Then you can log in to that URL, for example `https://ferry.apps.example.com`.

See [Production setup](/docs/guides/production).
