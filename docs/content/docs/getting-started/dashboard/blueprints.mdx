A <Term id="blueprint" /> is a file that describes your services and datastores.

## Do it

<Steps>
<Step>

### Put the file in the editor

Paste or open a `ferry.yaml` or a `render.yaml`. To start from a model, click **Example**.

</Step>
<Step>

### Click **Dry run**

The shortcut is <kbd>⌘</kbd>+<kbd>Enter</kbd> or <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.

The <Term id="dry-run" /> shows what Ferry will create, update or not change. It gives a warning for each key that Ferry does not support.

</Step>
<Step>

### Click **Apply**

Ferry deploys the new services and the changed services.

</Step>
</Steps>

## What Apply does to a service

| The service | Ferry |
|---|---|
| Is new | Deploys it |
| Has changed settings | Deploys it |
| Has only changed variables | Restarts it |

**Apply** deletes nothing. See [Blueprint spec](/docs/reference/blueprint).
