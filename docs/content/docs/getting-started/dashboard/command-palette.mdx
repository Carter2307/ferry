The <Term id="command-palette" /> is a search box that opens on top of the page.

## Open it

Press <kbd>⌘</kbd>+<kbd>K</kbd> or <kbd>Ctrl</kbd>+<kbd>K</kbd>. The search field in the top bar opens it too.

## What it does

| Group | Actions |
|---|---|
| Go to | A service, a datastore, an env group or a page |
| A service | Open one of its sections |
| The current service | **Manual deploy** or **Restart service** |
| Create | A service |
| The dashboard | Change the theme, or sign out |
