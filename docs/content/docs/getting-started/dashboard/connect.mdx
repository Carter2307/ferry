## What the panel has

| Value | Where |
|---|---|
| The `ferry login` command for this server | On each page |
| The API URL | On each page |
| The URL of the service | On a service page |
| The private address of the service | On a service page |
| The <Term id="deploy-hook" /> of the service | On a service page |

Each value has a copy button.

## Use it

Click **Connect**. Copy the `ferry login` command. Paste it in a <Term id="terminal" />.

The command has the address of this server. See [Log in](/docs/getting-started/cli/login).
