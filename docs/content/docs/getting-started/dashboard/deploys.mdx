## The list

| Column | Content |
|---|---|
| Status | The [status](/docs/concepts/deploys/statuses) of the deploy |
| Deploy id and <Term id="trigger" /> | Upload, manual deploy, rollback, restart, environment change… |
| Source | A commit, an uploaded archive, an image, or "Reused image from dep-…" |
| Image, duration, age | |

## The row menu

| Item | On which deploy |
|---|---|
| Open the deploy | Each deploy |
| **Roll back to this deploy** | An earlier deploy that went live. See [Roll back](/docs/concepts/deploys/rollbacks). |
| **Cancel deploy** | A deploy in progress. See [Cancel a deploy](/docs/concepts/deploys/cancel). |

## The page of a deploy

The page shows the trigger, the source, the commit, the image, the timestamps, the duration and the port.

If the deploy failed, the **Why it failed** box shows the error.

The **Build & deploy log** is the <Term id="deploy-log" />. It shows new lines until the deploy stops. See [Deploys](/docs/concepts/deploys).
