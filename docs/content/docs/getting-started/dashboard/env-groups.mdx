## The list

Each <Term id="env-group" /> is a card. The card shows the keys of the group and its linked services.

## The page of a group

| Part | Use |
|---|---|
| The variables | The same editor as on [the Environment page](/docs/getting-started/dashboard/environment) of a service. |
| **Linked services** | The services that use the group. **Link service** adds one. |
| **Danger zone** | Delete the group. |

## Save

| Button | Effect |
|---|---|
| **Save only** | Ferry keeps the variables for the next deploy or restart. |
| **Save & restart** | Ferry restarts the linked services that are live. |

See [Environment & env groups](/docs/concepts/environment).
