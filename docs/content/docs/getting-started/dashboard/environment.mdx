## The four cards

| Card | Use |
|---|---|
| **Service variables** | Edit each <Term id="env-var" /> of the service: a key and a value. |
| **Linked environment groups** | Link or unlink an <Term id="env-group" />. |
| **Effective environment** | The <Term id="merged-env" /> of the next deploy or restart. Each variable shows its source: the service or a group. |
| **Reference syntax** | How to write `${{datastore.NAME.connectionString}}` and `${{service.NAME.hostport}}`. It lists the references that you can insert for your datastores and services. |

**Show Ferry variables** adds each <Term id="injected-variable" /> to the list, for example `PORT`.

## Edit the variables

- The values stay hidden. Click **Reveal** to show them.
- **Copy .env** copies all the variables.
- Add the variables one at a time, or import a `.env` file.
- You can also paste `KEY=value` lines into a key field.

## Save

| Button | Effect |
|---|---|
| **Save only** | Ferry keeps the variables for the next deploy or restart. |
| **Save & restart** | Ferry applies the variables immediately. |

See [Environment & env groups](/docs/concepts/environment).
