The <Term id="dashboard" /> is part of <Term id="ferryd" />. All that the <Term id="cli" /> does, the dashboard does too.

You create and deploy services, read build logs, roll back and edit variables. You control datastores and env groups, and you apply blueprints.

A change from the CLI, the API, a webhook or another browser tab shows on the screen in about one second.

## Open it

```text title="Browser"
http://127.0.0.1:7878
```

The [CLI](/docs/getting-started/cli) does the same actions from a terminal. The two use the same [API](/docs/reference/api).
