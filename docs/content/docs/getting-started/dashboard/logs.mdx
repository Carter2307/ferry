The page shows the <Term id="stdout" /> and the <Term id="stderr" /> of the instances that run. This is the <Term id="runtime-log" /> of the service.

## The tools

| Tool | Use |
|---|---|
| History | Load the last 100, 500 or 1000 lines, or all the lines. |
| Pause, resume | Stop the live list, then start it again. |
| Search | Find text in the lines. |
| Wrap | Wrap the long lines. |
| Columns | Show or hide the timestamps and the instance column. |
| Download | Save the lines that are on the screen. |

## Read old lines

Scroll up. The auto-scroll stops. Click **Jump to latest** to start it again.

See [Logs & events](/docs/concepts/logs).
