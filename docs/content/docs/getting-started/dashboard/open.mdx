## The two addresses

| Address | What it is |
|---|---|
| `http://127.0.0.1:7878` | The <Term id="api" /> address. |
| `http://ferry.localhost:8080` | The public <Term id="proxy" />. It is on by default for a local base domain such as `localhost`. |

These are the addresses with the default settings. Then [sign in](/docs/getting-started/dashboard/sign-in).

## On a remote server

Open an <Term id="ssh-tunnel" /> first. Then open `http://127.0.0.1:7878` in your browser.

```bash title="Terminal"
ssh -L 7878:127.0.0.1:7878 you@your-server
```

You can also put the dashboard on a public name with <Term id="https" />. See [Production setup](/docs/guides/production).

<Callout type="warning" title="The dashboard is the admin API">
A person who can sign in to the dashboard controls the full server. The server has one administrator <Term id="admin-account" />. It has no other users and no roles.
</Callout>

<Accordions>
  <Accordion title="The dashboard on a public domain">
    On a public domain, `ferryd` does not send the dashboard through the proxy. To change that, start `ferryd` with `--dashboard-host`. This flag sets the <Term id="dashboard-host" />. Do this only when HTTPS is on.
  </Accordion>
</Accordions>
