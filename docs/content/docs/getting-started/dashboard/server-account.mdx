## Password

The section shows the email of your account. **Change password** asks for the current password. Then it signs out each other browser.

## API tokens

**API tokens** lists the tokens of the CLI and of scripts. An <Term id="api-token" /> shows its name, its last 4 characters, its last use and its expiry.

| Button | Effect |
|---|---|
| **New token** | You give a name and an expiry: never, 30 days, 90 days or 1 year. The dashboard shows the token one time. |
| **Revoke** | The token stops immediately. |

A token from `ferry login` has the name of its terminal, for example `ada@laptop`.

## Sessions

**Sessions** lists the browsers that have a <Term id="browser-session" /> on the account. Each line has a **Sign out** button.
