Ferry serves your services under the domains of the server. See [Domains](/docs/guides/domains).

## The list of domains

Each <Term id="domain" /> shows its state: Active, Waiting for DNS, Misconfigured or Local. One domain is the <Term id="default-domain" />.

A domain is Active when it reaches the server. To connect one, you create a <Term id="dns-record" /> at your DNS provider.

| Button | Effect |
|---|---|
| **Verify now** | Ferry tests the domain again. |
| **Make default** | The domain becomes the default domain. |
| **Disconnect** | Ferry removes the domain from the server. |

## Certificates

**Certificates** lists each hostname that the proxy serves, with the state of its <Term id="certificate" />.

| State | What you see |
|---|---|
| Issued | The date when the certificate expires |
| Pending or Issuing | Ferry asks for the certificate |
| Failed | The cause, and the time of the next try |
