Click **Server** in the icon rail. A side menu shows the five sections.

## The sections

| Section | Content |
|---|---|
| **General** | The versions of Ferry and Docker. The default limits of a container, with the CPUs and the memory of the Docker host. The default domain, the proxy URL and the dashboard URL. If TLS and the GitHub webhook are on. The state of the live updates. The theme. |
| **Domains** | See [Server: Domains](/docs/getting-started/dashboard/server-domains). |
| **Account** | See [Server: Account](/docs/getting-started/dashboard/server-account). |
| **Connections** | The `ferry login` command. The `FERRY_SERVER` and `FERRY_TOKEN` variables for CI. The connected GitHub and GitLab accounts. The settings of the GitHub webhook. A link to the deploy hooks of the services. |
| **API** | The base URL. How to authenticate: an <Term id="api-token" /> as a bearer token. An example request. Links to the <Term id="swagger-ui" /> at `/api/docs` and to the <Term id="openapi" />. The streams of <Term id="sse" />. |
