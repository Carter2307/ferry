## The header

The header shows the name, the state, the type and the URL of the <Term id="service" />. It has two buttons: **Open** and **Manual deploy**.

## The arrow next to Manual deploy

| Item | Use |
|---|---|
| **Deploy latest commit** | The deploy of a service from a git repository. |
| **Pull & deploy image** | The deploy of a service from an image. Ferry pulls the image again. |
| **Redeploy last upload** | The deploy of a service from an upload. |
| **Clear build cache & deploy** | For a service that Ferry builds. |
| **Restart service** | A [restart](/docs/concepts/deploys/restarts). |
| **Suspend service** | Stop the service. See [Scaling](/docs/concepts/scaling). |

The menu shows one of the first three items. The item depends on the source of the service.
