The source on a card is a repository and its branch, an image, or the text `Upload via ferry up`.

## Find a service

| Tool | Use |
|---|---|
| **Search** | Find a service by its name. |
| **Status** | Filter: live, deploying, degraded, failed, suspended, not deployed. |
| Sort | By name or by last deploy. |
| View | Grid or list. |

## The ⋮ menu of a card

The menu has these actions: open, deploy, restart, suspend or resume, copy the URL, delete.

## The Ferry server panel

The **Ferry server** panel is on the right side. It shows:

- The versions of Ferry and Docker.
- The address of the proxy.
- The number of services, datastores, env groups and live instances.

While the dashboard gets [live updates](/docs/getting-started/dashboard/live-updates), the bottom of the panel shows **Live updates**.
