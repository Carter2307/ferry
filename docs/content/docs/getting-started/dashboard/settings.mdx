## The sections

| Section | What you change |
|---|---|
| **General** | Nothing. It shows the name, the id, the type, the private address and the creation date, with copy buttons. |
| **Build & deploy** | The source (git, image or upload), branch, runtime, root directory, Dockerfile path, build command, start command, publish directory, port, health check path, auto-deploy. |
| **Cron schedule** | The schedule of a cron job. It has common presets. |
| **Scaling** | The instances and the disk mount path. |
| **Resources** | The memory limit and the CPU limit: **Server default**, a preset or **Custom…**. |
| **Custom domains** | Add or remove domains. It lists each host that the proxy sends to the service. |
| **Deploy hook** | Copy the secret deploy URL, or make a new one. Then the old URL stops. |
| **Danger zone** | Suspend or resume the service. Delete the service. |

## If the settings change in another place

It is possible that a setting changes in another place while you edit the form. Then the page shows **These settings changed elsewhere**.

You choose: keep your edits, or load the latest values. Thus you do not replace the change of another person by accident.
