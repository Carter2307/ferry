| Render feature | In Ferry |
|---|---|
| Deploy from Git, auto-deploy on push | Yes: a GitHub <Term id="webhook" /> (`/hooks/github`), and each git URL, also a path on the server |
| Zero-downtime deploys, health checks | Yes: each deploy is blue-green. `--health` sets the <Term id="health-check" /> path. |
| <Term id="rollback">Rollbacks</Term>, deploy history, build logs | Yes |
| Manual deploys, <Term id="deploy-hook">deploy hooks</Term> | Yes: a secret URL, `/hooks/deploy/{id}?key=…` |
| Suspend, resume, restart | Yes |

## Only in Ferry

```bash title="Terminal"
ferry up
```

`ferry up` deploys a local folder without git. Render does not have this command.

Read more: [Deploys](/docs/concepts/deploys) and [Auto-deploy from GitHub](/docs/guides/github-auto-deploy).
