Ferry is a <Term id="self-hosted" /> alternative to <Term id="render" />. It builds your code, deploys it with <Term id="zero-downtime" /> and gives it a URL.

Ferry also scales, repairs and logs your apps. It runs Postgres and Redis, <Term id="cron-job">cron jobs</Term>, <Term id="env-group">env groups</Term>, and custom domains with automatic <Term id="https" />.

## Use your render.yaml

```bash title="Terminal"
ferry blueprint apply
```

Ferry reads the same <Term id="blueprint" /> file as Render. See [Migrate from Render](/docs/guides/migrate-from-render).
