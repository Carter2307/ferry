Thus <Term id="docker-desktop" /> works with no change. `ferryd` finds its <Term id="docker-socket">socket</Term>, `~/.docker/run/docker.sock`.

## Colima or OrbStack

These tools use another <Term id="docker-context" />. Give its socket to `ferryd` before you start it.

```bash title="Terminal"
export DOCKER_HOST=$(docker context inspect --format '{{.Endpoints.docker.Host}}')
```
