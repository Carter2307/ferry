| What | Default address | Flag |
|---|---|---|
| API and dashboard | `http://127.0.0.1:7878` | `--api-addr` |
| Public HTTP <Term id="proxy" />, where your apps are | `0.0.0.0:8080` | `--proxy-addr` |
| Public HTTPS proxy | off | `--https-addr` with `--acme-email` |

## The URLs with the defaults

| What | URL |
|---|---|
| Dashboard | http://127.0.0.1:7878, or http://ferry.localhost:8080 through the proxy |
| Your apps | `http://<name>.localhost:8080` |
| <Term id="swagger-ui" /> of your server | http://127.0.0.1:7878/api/docs |
| <Term id="openapi" /> (3.1) | `/api/openapi.json` |
| <Term id="liveness-probe">Liveness probe</Term> | `/healthz` answers `ok` |

Browsers send each `*.localhost` name to `127.0.0.1`. Thus you set up no <Term id="dns" /> on your machine.

## Reach the API from another machine

```bash title="Terminal"
ssh -L 7878:127.0.0.1:7878 your-server
```

Use this <Term id="ssh-tunnel" />. Do not open the API to the public. See [Production setup](/docs/guides/production).
