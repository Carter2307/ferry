Ferry runs on Linux and macOS.

| Tool | Version | Use |
|---|---|---|
| <Term id="docker" /> | Engine 27.3 or newer, or <Term id="docker-desktop" /> | Runs everything. Builds use the `docker` CLI with <Term id="buildkit" />. |
| git | A recent version | Clones repositories for git deploys |
| <Term id="rust" /> | Stable 1.89 or newer (install it with [rustup](https://rustup.rs)) | Builds `ferryd` and `ferry` |
| Node.js | 20.19 or newer, with <Term id="npm" /> | Builds the dashboard |

<Accordions>
  <Accordion title="Why Docker 27.3">
    Your build gets its environment variables as BuildKit secrets (`RUN --mount=type=secret,…,env=…`). These secrets need Docker Engine 27.3 or newer.

    With an older engine, a build that uses environment variables fails. The message tells you to upgrade. See [Builds & runtimes](/docs/concepts/builds).
  </Accordion>
</Accordions>
