```bash title="Terminal"
ferryd stop   # stop the server
ferryd        # start it again
```

For a server in the foreground, press <kbd>Ctrl</kbd>+<kbd>C</kbd> in its terminal.

At the next start, `ferryd` reads the same data directory. It puts the routes back and brings each service back to its <Term id="desired-state" />. See [Self-healing](/docs/concepts/self-healing).

## What a stop does

The stop is a <Term id="graceful-shutdown" />.

| What | During the stop |
|---|---|
| Open API requests | They get up to 10 seconds. |
| Jobs in progress | The engine stops them. |
| Deploys in progress | The engine records them as [interrupted](/docs/concepts/deploys/interrupted). |

The engine does its part in 25 seconds at most.

<Accordions>
  <Accordion title="Stop immediately">
    Run `ferryd stop` a second time, or press <kbd>Ctrl</kbd>+<kbd>C</kbd> a second time, while the server stops. The server exits immediately.
  </Accordion>
</Accordions>
