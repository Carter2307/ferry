## Try it

Deploy with a start command that crashes.

<Terminal
  lines={[
    '$ ferry up --start-cmd "node crash.js" --follow',
    "Updated 'node-hello': start command",
    '…',
    "09:37:33 [d1c6b8] Error: Cannot find module '/app/crash.js'",
    '…',
    '09:37:34 ==> Removing 1 new instance(s)',
    '09:37:34 ==> Deploy failed: instance d1c6b8 crashed (exit code 1)',
    'Deploy dep-ca4bc7b5862742959b70 failed (deploy_failed): instance d1c6b8 crashed (exit code 1)',
  ]}
/>

The command stops with <Term id="exit-code" /> 1. The previous deploy continues to answer.

If an instance crashes during the <Term id="health-check" />, the log also shows the last 50 lines of its output.

## Repair it

Remove the setting and deploy again.

```bash title="Terminal"
ferry up --start-cmd "" --follow
```
