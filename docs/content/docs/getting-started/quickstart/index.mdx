You deploy `examples/node-hello`, a small Node.js <Term id="web-service" /> from the Ferry repository. Ferry takes it from your disk: you need no git repository and no <Term id="dockerfile" />.

First, build `ferryd` and `ferry`. See [Installation](/docs/getting-started/installation).

## The three commands

```bash title="Terminal"
# 1. Start the server. Then open the link that it prints.
ferryd

# 2. Connect the CLI.
ferry login --server http://127.0.0.1:7878

# 3. Deploy the app.
cd examples/node-hello
ferry up --follow
```

The output on the next pages comes from a real run. Ids, times and ports are different on your machine.
