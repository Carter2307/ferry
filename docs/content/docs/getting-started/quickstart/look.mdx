| Command | Shows |
|---|---|
| `ferry services` | The list of your services |
| `ferry status node-hello` | Each <Term id="instance" />, with its CPU and memory use next to its limits (`4.7% / 1 CPU`) |
| `ferry logs node-hello` | The log. Each line shows the time and the instance. |
| `ferry open node-hello` | Prints the URL and tries to open it in your browser |

## Follow the log

```bash title="Terminal"
ferry logs node-hello -f
```

`-f` continues with the new lines. Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop.

## In the dashboard

Open http://127.0.0.1:7878. You do not need to sign in again. Open **node-hello**. See the [Dashboard tour](/docs/getting-started/dashboard).
