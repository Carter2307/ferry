`ferry up` works for each folder that Ferry can build. `ferry create` makes a <Term id="service" /> from a <Term id="repository" /> or an <Term id="image" />.

## Four examples

```bash title="A static site: nginx serves the folder as it is"
ferry up my-site --dir ./public --type static
```

```bash title="A git repository, with 2 instances and an HTTP health check"
ferry create api --repo https://github.com/you/api --branch main --instances 2 --health /healthz --follow
```

```bash title="A prebuilt image"
ferry create hello --image nginx:alpine --port 80
```

```bash title="A cron job that runs each night at 03:00 UTC"
ferry create nightly --type cron --image busybox:stable --schedule "0 3 * * *" --start-cmd 'echo hello'
```
