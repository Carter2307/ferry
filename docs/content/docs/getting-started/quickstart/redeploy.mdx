## What Ferry did

The service exists already. Thus `ferry up` only uploads and deploys.

The old container answered until the new container passed its <Term id="health-check" />. Then the proxy moved the traffic, and Ferry stopped the old container.

This is a blue-green deploy with <Term id="zero-downtime" />. See [Deploys](/docs/concepts/deploys).
