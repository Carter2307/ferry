## What Ferry did

[`ferry rollback`](/docs/reference/cli#ferry-rollback) uses the <Term id="image" /> of that deploy again. Ferry builds nothing.

A <Term id="rollback" /> is a new deploy with the <Term id="trigger" /> `rollback`. It shows at the top of `ferry deploys`. You can roll it back too.

More in [Roll back](/docs/concepts/deploys/rollbacks).
