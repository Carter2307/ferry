At your <Term id="dns-provider" />, point the domain to the server.

| Domain | <Term id="dns-record">Record</Term> |
|---|---|
| A <Term id="subdomain" />, like `shop.example.com` | `CNAME` to a name that <Term id="resolve">resolves</Term> to the server (for example `shop.apps.example.com`), or `A`/`AAAA` records |
| The <Term id="apex">apex</Term>, like `example.com` | `A` (and `AAAA`) records with the <Term id="ip-address">IP addresses</Term> of the server |

## Wait for the DNS

```bash title="Terminal"
dig +short shop.example.com
```

Run the command again until it shows an answer. Then the name resolves.
