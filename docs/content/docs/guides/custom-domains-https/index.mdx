A <Term id="custom-domain" /> is one more <Term id="hostname" /> for a <Term id="web-service" /> or a <Term id="static-site" />. Ferry routes it when you add it.

With automatic <Term id="https" /> on, Ferry gets a <Term id="certificate" /> from <Term id="lets-encrypt" />. The test of Let's Encrypt is the <Term id="http-01" />.

To serve each service at `<service>.example.com` with one DNS record, [connect the domain to the server](/docs/guides/domains).

## Add a custom domain

```bash title="Terminal"
ferry domains add shop shop.example.com
```
