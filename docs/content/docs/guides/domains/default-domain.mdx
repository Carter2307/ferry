The <Term id="default-domain" /> sets the URL of a service in three places.

| Place | What uses the default domain |
|---|---|
| The dashboard | The URL of each service |
| The CLI | The command `ferry open` |
| Your app | The <Term id="env-var">variable</Term> `FERRY_EXTERNAL_URL` |

## Change the default domain

<Terminal
  lines={[
    '$ ferry domains default example.com',
    'example.com is the default domain: services are shown at https://<service>.example.com',
  ]}
/>

## The rules

- Only a domain that Ferry serves can be the default.
- A service reads its new `FERRY_EXTERNAL_URL` at its next deploy or restart.
- If the default was a <Term id="local-name" /> such as `localhost`, the first domain that becomes active becomes the default.
- If you disconnect the default domain, the <Term id="base-domain" /> becomes the default again.
