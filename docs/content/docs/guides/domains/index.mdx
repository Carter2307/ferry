A <Term id="server-domain" /> is a name that Ferry serves your services under. Connect `example.com`. Then each <Term id="web-service" /> and <Term id="static-site" /> answers at `<service>.example.com`.

A server starts with one domain: its <Term id="base-domain" /> (`--base-domain`). The default is `localhost`, which works only on the machine itself. You connect more domains while the server runs: no <Term id="restart" />, no <Term id="deploy" />.

## Connect a domain

```bash title="Terminal"
ferry domains connect example.com
```
