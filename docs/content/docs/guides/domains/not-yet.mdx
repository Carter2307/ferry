| Not in Ferry | What to do |
|---|---|
| <Term id="wildcard-certificate">Wildcard certificates</Term> | Nothing. Ferry asks for one certificate for each hostname. |
| The DNS record | Create the record at your <Term id="dns-provider" />. |
| The dashboard under a connected domain | Set the hostname of the dashboard at the start of the server: `--dashboard-host`. |
| HTTPS from the dashboard | Set the HTTPS options at the start of `ferryd`. |

## Why

One certificate for `*.example.com` needs access to the <Term id="api" /> of your DNS provider. Ferry does not have this access. For the same reason, Ferry cannot create the DNS record for you.
