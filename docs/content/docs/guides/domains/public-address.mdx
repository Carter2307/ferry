The <Term id="public-address" /> is the value of the <Term id="dns-record">DNS records</Term>. Ferry finds its IPv4 address without your help.

## Give the address

```bash title="Terminal"
ferryd … --public-ip 203.0.113.10 --public-ip 2001:db8::10
```

With `--public-ip`, Ferry asks no public service.

## IPv6

`--public-ip` is the only way to get `AAAA` records. Ferry does not guess an <Term id="ipv6" /> address. The IPv6 address that a machine uses to connect to other machines is frequently temporary.
