Ferry has two types of domain: the <Term id="server-domain" /> and the <Term id="custom-domain" />. You can use the two together.

| | Domain of the server | Custom domain |
|---|---|---|
| Covers | Each service | One service |
| <Term id="hostname">Hostname</Term> | `<service>.example.com` | `www.example.com`, or the domain itself |
| DNS | One <Term id="wildcard-record" /> | One record for each name |
| Command | `ferry domains connect` | `ferry domains add` |

## Which guide to read

- For one record that covers all your services, continue with this guide.
- For one more name on one service, read [Custom domains & HTTPS](/docs/guides/custom-domains-https).
