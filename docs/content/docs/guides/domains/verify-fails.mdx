Run `ferry domains` to read the result of the last check.

| What Ferry found | What to do |
|---|---|
| No DNS record answers for `*.example.com` | Create the record. A new record can take some minutes to show. |
| The name <Term id="resolve">resolves</Term> to another address | Point the record to the address that Ferry shows. |
| The name resolves to many addresses, and only one is this server | Remove the other records. Visitors that go there do not reach your services. |
| Another server answers | The record points to a machine that is not this Ferry server. Or another program listens on port 80. |
| This server could not reach itself | This is not a failure. See the note below. |
| The name resolves to a <Term id="private-address" /> | The name works from the server and its network, not from the internet. |

## If the server cannot reach itself

Some networks do not let a machine connect to its own <Term id="public-address" />. Ferry shows a warning, and the domain can become active.

If visitors cannot reach your services, open port 80 in the <Term id="firewall" />.
