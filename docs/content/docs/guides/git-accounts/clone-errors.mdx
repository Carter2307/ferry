## A repository is not in the list

| Connection | Why, and what to do |
|---|---|
| GitHub | The app reads only the repositories that you chose. Click **Change them on GitHub** and add the repository. A repository of an organization needs a connection to the organization. |
| GitLab, or a token | The account cannot see it. You must be a member of the project. A classic GitHub token needs `repo` and, in some organizations, an SSO authorization. Ferry lists only the 1000 repositories with the newest updates. For an older repository, use the **Repository URL** tab. |

## The provider refuses the authorization

The repository list shows **… no longer accepts this authorization**. There are three possible causes:

- A person removed or deleted the app.
- A person revoked the authorization of the application.
- The token expired.

Use the button next to the message to connect again.

## A deploy cannot clone

The <Term id="deploy" /> fails with **Authentication failed** or **repository not found**. A `==> Hint` line comes after it. The remote refused the <Term id="clone" />.

The hint tells you what to do:

- Add the repository to the installation of the app.
- Connect the account again.
- If no account is there, connect the account of the repository.
