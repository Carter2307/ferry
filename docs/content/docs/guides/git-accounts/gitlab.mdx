GitLab cannot create an application for Ferry. Thus you create an <Term id="oauth-app" /> for your server, one time. Each later authorization on the same GitLab uses it again.

## Connect the account

<Steps>
<Step>

### Open the GitLab page

Click **Connect GitLab**. Then click **Open GitLab applications** in the dialog. GitLab opens **User settings → Applications**.

</Step>
<Step>

### Add an application

Add an application with these values:

| Field | Value |
|---|---|
| Name | Your choice, for example `Ferry` |
| <Term id="redirect-uri">Redirect URI</Term> | Copy it from the dialog: `https://<your dashboard>/git/callback` |
| Confidential | checked |
| <Term id="scope">Scopes</Term> | `read_api` and `read_repository` |

Save the application. GitLab shows its **Application ID** and its **Secret**.

</Step>
<Step>

### Paste the ID and the Secret

Paste the two values in the dialog of Ferry. Click **Continue to GitLab**.

</Step>
<Step>

### Authorize the application

GitLab asks if the application can use your account. Click **Authorize**.

GitLab sends you back to Ferry. Ferry shows the account as connected.

</Step>
</Steps>

## A self-managed GitLab

Before you click **Continue to GitLab**, open **Self-hosted GitLab**. Enter the address of your GitLab, for example `https://gitlab.example.com`.
