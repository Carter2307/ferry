A <Term id="git-connection" /> is a GitHub or GitLab account that lets your Ferry server read its <Term id="repository">repositories</Term>. You give the permission on a page of the <Term id="git-provider" />. You type no token.

A connection does two things:

- The <Term id="dashboard" /> lists the repositories and the <Term id="branch">branches</Term> of the account. You choose what to deploy from a list.
- Ferry <Term id="clone">clones</Term> the repositories with the account. A private repository needs no credentials in its URL.

It works with github.com, gitlab.com, GitHub Enterprise Server and self-managed GitLab.

<Callout title="The connection belongs to the server">
You connect an account one time. Then each <Term id="service" /> of the server uses it.
</Callout>

## Where to connect

If the server has no connected account, the home page of the dashboard shows **Connect GitHub** and **Connect GitLab**.

You can also connect from these places:

- **+ New service → Git repository → Connected account**
- **Server → Connections → Git accounts**
