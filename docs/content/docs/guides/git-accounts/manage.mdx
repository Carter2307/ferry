Open **Server → Connections → Git accounts**. The page lists the <Term id="git-connection">connections</Term>, the method of each authorization and the services that each connection clones for.

## The actions

| Action | What it does |
|---|---|
| **Repositories** (GitHub) | Opens the page of the app on GitHub. There you add or remove repositories. |
| **Authorize again** | Repeats the authorization. Use it after you revoke the authorization on GitLab. Also use it when the repository list shows that the provider refuses the authorization. |
| **Finish connecting** | Continues an authorization that you did not complete. |
| **Replace token** | For an account with an <Term id="access-token" />: stores a new token. |
| **Disconnect** | Deletes the copy of the connection in Ferry. |

## After a disconnect

The services keep their repository. From then on, Ferry clones it with no credentials. A private repository then fails to deploy.

## Remove the access on the provider

| Provider | Do this |
|---|---|
| GitHub | Delete the GitHub App: **Settings → Developer settings → GitHub Apps**. |
| GitLab | Revoke the authorization of the application: **User settings → Applications**. |
