You choose nothing for each <Term id="service" />. Ferry reads the URL of the <Term id="repository" /> each time it deploys. This applies to a service from the dashboard, the <Term id="cli" />, a <Term id="blueprint" /> or the <Term id="api" />.

Example: you connect the account `you`. Immediately, Ferry <Term id="clone">clones</Term> each repository on `github.com/you/…` with it.

## URLs that get an account

| URL of the repository | Account |
|---|---|
| `https://` or `http://`, on the host of a connected account (for example `github.com`) | Yes |
| An SSH URL | No |
| A path on the server | No |
| A different host | No |
| A URL with its own credentials | No |

## An organization on GitHub

A <Term id="github-app" /> reads only the account where you installed it. To deploy the repositories of an organization, connect the organization too.

## See the account of a service

Open **Settings → Build & deploy** of the service. The page shows the account that clones the repository. It has the same **Branch** list.
