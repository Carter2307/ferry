When you <Term id="git-push">push</Term> to a <Term id="branch" />, GitHub sends a `push` event to the <Term id="webhook" /> endpoint of Ferry: `/hooks/github`. Ferry checks the <Term id="webhook-signature" />. Then Ferry deploys the <Term id="commit" /> of the push for each <Term id="service" /> that tracks this <Term id="repository" /> and this branch.

## Create a service that deploys on a push

```bash title="Terminal"
ferry create api --repo https://github.com/you/api --branch main --follow
```

<Term id="auto-deploy">Auto-deploy</Term> is on by default. GitHub must also tell Ferry about each push. If you connect your GitHub account from the public address of the server, GitHub does that. You add nothing to the repository.
