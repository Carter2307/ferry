## What you need

- A Ferry server that GitHub can reach through <Term id="https">HTTPS</Term>.
- The `ferry` <Term id="cli" />, with a login to that server.

## Why the dashboard host

The <Term id="api" /> serves the <Term id="webhook" /> endpoint. To open the API to GitHub, start `ferryd` with `--dashboard-host`, together with [automatic HTTPS](/docs/concepts/networking). Then the <Term id="proxy" /> sends the requests for that <Term id="dashboard-host" /> to the API.

The [Production setup](/docs/guides/production) guide shows the two settings.

<Callout type="warning" title="The dashboard host opens the full API">
`--dashboard-host` sends the dashboard, the REST API and the webhooks through the public proxy. Each API call still needs an <Term id="api-token" /> or a signed-in session. But use it only with HTTPS. Then the password, the session and the tokens never travel in clear text.
</Callout>
