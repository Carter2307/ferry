This site is a <Term id="static-export" />. `npm run build` in `docs/` writes plain HTML, the search index and the <Term id="open-graph" /> images to `docs/out/`.

Each static host can serve these files. Ferry serves them as a [static site](/docs/guides/language-guides) with <Term id="nginx" />.

## The main command

```bash title="Terminal"
ferry up ferry-docs --dir out --type static --follow
```
