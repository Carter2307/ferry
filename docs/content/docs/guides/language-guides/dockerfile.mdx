A <Term id="dockerfile" /> at the root always wins over the detection. Ferry builds the <Term id="image" /> from it.

## A Dockerfile in a different place

```bash title="Terminal"
ferry up api --dockerfile docker/Dockerfile --follow
```

The path of `--dockerfile` is relative to the <Term id="root-directory" />. This flag also changes an `auto` service to Docker builds.

## What changes with a Dockerfile

| Setting | With your Dockerfile |
|---|---|
| Port | `--port`, a `PORT` variable, or the one port that the image exposes (`EXPOSE`). If there is none: `10000`. |
| <Term id="start-command">Start command</Term> | It replaces the command of the image. Ferry runs it as `/bin/sh -c "<command>"`. |
| Build command, publish directory | They do not apply. The Dockerfile does the build. |
