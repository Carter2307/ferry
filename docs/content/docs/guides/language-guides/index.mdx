You do not need a <Term id="dockerfile" />. When the <Term id="runtime" /> of a <Term id="service" /> is `auto` (the default), Ferry looks at the root of the source. Then Ferry writes a Dockerfile for the first file that it knows.

## Deploy an example

```bash title="Terminal"
ferry up hello-node --follow
```

Each example of this section deploys from its directory with [`ferry up`](/docs/reference/cli#ferry-up). The command creates the service, uploads the files and shows the build. The same settings work with `ferry create NAME --repo URL`.
