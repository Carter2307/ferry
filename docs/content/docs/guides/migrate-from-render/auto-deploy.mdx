With <Term id="auto-deploy" />, a service deploys again after each push. The key `autoDeploy` is on by default. It works when GitHub sends <Term id="webhook">webhooks</Term> to Ferry.

<Steps>
<Step>

### Connect GitHub to Ferry

Follow [Auto-deploy from GitHub](/docs/guides/github-auto-deploy).

</Step>
<Step>

### Stop the deploys on Render

Remove the webhook of the Render service, or disconnect the service. Then a push does not deploy two times.

</Step>
</Steps>
