| You need | Details |
|---|---|
| A Ferry server with <Term id="docker" /> | The internet must reach it at the domains that you use. See [Production setup](/docs/guides/production). |
| The `ferry` <Term id="cli" /> | Log in to the server with it. |
| <Term id="repository">Repositories</Term> that the server can reach | Public, or with credentials in the URL, or over <Term id="ssh" />. See [Auto-deploy from GitHub](/docs/guides/github-auto-deploy). |

## Private repositories on GitHub or GitLab

[Connect the account](/docs/guides/git-accounts) to the server before you apply the <Term id="blueprint" />.

Then Ferry clones each repository of that account with it. You add nothing to the blueprint.
