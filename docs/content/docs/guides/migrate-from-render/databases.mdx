| Key | On Ferry |
|---|---|
| `name` | Supported. |
| `postgresMajorVersion` | The <Term id="postgres" /> version: `postgres:<version>-alpine`. The default is `16`. |
| `databaseName`, `user` | Supported. |
| `plan` | The <Term id="memory-limit" /> of the <Term id="container" />. See [Plans](/docs/guides/migrate-from-render/plans). |
| `memoryLimit`, `cpuLimit` | Ferry keys: they set the limits directly and replace the limits of the plan. |
| All other keys (`region`, `ipAllowList`, `readReplicas`, …) | Ferry ignores them, with a warning. |

## See the result

```bash title="Terminal"
ferry db show shop-db
```

To copy the data, see [Move your Postgres data](/docs/guides/migrate-from-render/postgres-data).
