The blueprint lists your <Term id="custom-domain">custom domains</Term> under `domains:`.

<Steps>
<Step>

### Add the DNS records

At your <Term id="dns-provider" />, add the <Term id="dns-record">DNS records</Term> of each custom domain. They must point to the Ferry server. See [Create the DNS record](/docs/guides/custom-domains-https/dns-record).

</Step>
<Step>

### Wait for the certificate

With automatic <Term id="https" /> on, Ferry asks for a <Term id="certificate" /> for each domain when the domain resolves.

```bash title="Terminal"
ferry certificates
```

</Step>
</Steps>

See [Custom domains & HTTPS](/docs/guides/custom-domains-https) and [Networking](/docs/concepts/networking).
