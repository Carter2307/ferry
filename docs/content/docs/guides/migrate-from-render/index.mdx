Ferry reads the <Term id="blueprint" /> format of <Term id="render" />. One command creates the <Term id="env-group">env groups</Term>, the databases, the <Term id="key-value-store">key value stores</Term> and the services of the file. Then it deploys them.

Ferry ignores each key that it does not support, with a warning. Thus you can apply your file as it is, then repair what the warnings list.

## Apply your file

```bash title="Terminal"
ferry blueprint apply render.yaml
```
