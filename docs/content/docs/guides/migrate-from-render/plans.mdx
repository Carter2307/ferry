A <Term id="render-plan" /> sets the <Term id="resource-limit">resource limits</Term> of each <Term id="container" />.

## Examples

| Entry | `plan` | Memory | CPU |
|---|---|---|---|
| Service | `starter` | 512 MiB | 0.5 CPU |
| Service | `standard` | 2 GiB | 1 CPU |
| Service | `pro` | 4 GiB | 2 CPUs |
| Service | `free` | The memory of the plan | 0.5 CPU (0.1 on Render) |
| Postgres | `basic-1gb` | 1 GiB | Not set by the plan |
| Key Value | `starter` | 256 MiB | Not set by the plan |

The [blueprint reference](/docs/reference/blueprint/plans) lists each plan.

## Without a plan

A resource with no plan and no limit keys gets the defaults of the server: 512 MiB and 1 CPU for each container.

The server can have other defaults: `--default-memory-limit` and `--default-cpu-limit`.

## Set the limits directly

The keys `memoryLimit` and `cpuLimit` replace the limits of the plan. See the [blueprint reference](/docs/reference/blueprint/limit-keys).
