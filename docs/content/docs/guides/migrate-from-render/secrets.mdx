A <Term id="env-var">variable</Term> with `sync: false` has no value in the file. Thus Ferry does not create it. The <Term id="dry-run" /> lists each of these variables in a warning.

## Set each value

```bash title="Terminal"
ferry env set shop-web STRIPE_KEY=sk_live_…
```

Each command restarts the service.
