| Render `type` | Ferry |
|---|---|
| `web` | <Term id="web-service">Web service</Term>. With `runtime: static` (or the old `env: static`), a static site. |
| `pserv` | <Term id="private-service">Private service</Term>. |
| `worker` | <Term id="worker">Background worker</Term>. |
| `cron` | <Term id="cron-job">Cron job</Term>. |
| `static` | <Term id="static-site">Static site</Term>. |
| `redis`, `keyvalue` | A <Term id="redis" /> <Term id="datastore" />. |

## Key value stores

For a <Term id="key-value-store" />, Ferry uses only `name` and `plan`, and its own keys `memoryLimit` and `cpuLimit`.

Ferry ignores each other key, such as `ipAllowList` or `maxmemoryPolicy`, with a warning.
