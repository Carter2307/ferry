| Key | On Ferry |
|---|---|
| `services` | Supported. |
| `databases` | Supported (<Term id="postgres" />). |
| `envVarGroups` | Supported. |
| `projects` / `environments` | Ferry makes them flat. It applies the resources of each environment to this server, with a warning. |
| All other keys (`previews`, …) | Ferry ignores them, with a warning. |
