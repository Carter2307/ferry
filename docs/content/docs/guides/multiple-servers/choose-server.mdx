The <Term id="cli" /> uses a flag or an <Term id="env-var" /> before its saved config.

## Send one command to another server

```bash title="Terminal"
FERRY_SERVER=http://127.0.0.1:7879 FERRY_TOKEN=$(cat /var/lib/ferry-staging/api_token) ferry ls
ferry --server http://127.0.0.1:7879 --token fy_… ls
```

A token works only on the server that it belongs to.

## Where to get the token

| You are | Token |
|---|---|
| On the machine that runs the server | The <Term id="server-token" /> in its data directory. The first line above reads it. |
| On another machine | Create an <Term id="api-token" /> under **Server → Account** in the staging dashboard. |

<Callout type="warning" title="ferry login replaces the saved server">
`ferry login --server http://127.0.0.1:7879` also works. But it replaces the saved login.
</Callout>

See [Set up the CLI](/docs/getting-started/cli) for the config file, the flags and the variables.
