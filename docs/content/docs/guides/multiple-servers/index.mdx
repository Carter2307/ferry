More than one <Term id="ferryd" /> can share one <Term id="docker-daemon" />. For example, run a <Term id="staging" /> server and a production server on the same machine. Or run a temporary server for tests next to your real server.

## Start a second server

```bash title="Terminal"
ferryd --data-dir /var/lib/ferry-staging \
  --name-prefix staging \
  --api-addr 127.0.0.1:7879 \
  --proxy-addr 0.0.0.0:8081 \
  --base-domain staging.localhost
```
