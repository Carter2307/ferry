This procedure moves the <Term id="data-directory" /> on the same machine.

<Steps>
<Step>

### Stop ferryd

</Step>
<Step>

### Move the directory

Move or copy the full directory. Keep its permissions: mode `0700`, and the owner is the user that runs `ferryd`.

</Step>
<Step>

### Start ferryd

Start `ferryd` with the new `--data-dir` and **the same** `--name-prefix`.

</Step>
</Steps>

## If the server refuses the prefix

The cause: the <Term id="instance-id" /> file did not move. For example, you restored only `ferry.db`. Start the server one time with `--take-over`. The server replaces the marker with its own identity.

<Callout type="danger" title="Never use --take-over for a second server">
Do not use `--take-over` to start a second server on a prefix that another server uses. The new server removes the containers of the other server as orphans.
</Callout>
