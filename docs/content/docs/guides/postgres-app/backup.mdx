## Back up

Dump the database on a schedule, for example from a cron entry on the server. The tool is <Term id="pg-dump" />.

```bash title="Terminal"
docker exec ferry-ds-notes-db pg_dump -U notes_db notes_db > notes-$(date +%F).sql
```

## Restore

Restore into a new <Term id="datastore" />:

```bash title="Terminal"
docker exec -i ferry-ds-notes-db psql -U notes_db notes_db < notes-2026-09-27.sql
```

<Callout type="warning" title="If you delete the datastore, you delete the data">
`ferry db rm notes-db` removes the container and its <Term id="volume" />. While `notes` has a reference to the datastore, Ferry refuses, unless you add `--force`.
</Callout>
