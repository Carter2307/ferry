## From the server

Open <Term id="psql" /> in the <Term id="container" /> of the <Term id="datastore" />.

```bash title="Terminal"
docker exec -it ferry-ds-notes-db psql -U notes_db notes_db
```

The name of the container is `<prefix>-ds-<name>`. With the default prefix, it is `ferry-ds-notes-db`.

## From your machine

Use the <Term id="external-url" /> that `ferry db show notes-db` prints. Its port is open only on `127.0.0.1` of the server. Thus make an <Term id="ssh-tunnel" /> first.

```bash title="Terminal"
ssh -L 62975:127.0.0.1:62975 you@your-server
psql 'postgresql://notes_db:…@127.0.0.1:62975/notes_db'
```
