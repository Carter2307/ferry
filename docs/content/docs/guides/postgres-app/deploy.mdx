## What the reference does

`${{datastore.notes-db.connectionString}}` is a [reference](/docs/concepts/environment). The variable keeps the <Term id="reference" /> as you wrote it. Each <Term id="container" /> gets the real URL when it starts. The URL uses the <Term id="private-network" />: `notes-db:5432`.

| Part | Meaning |
|---|---|
| `datastore` | The kind of thing |
| `notes-db` | The name of the datastore |
| `connectionString` | The property: the internal URL |

The [Env var references](/docs/reference/env-references) page lists all the properties.

<Callout type="warning" title="Keep the single quotes">
Without the single quotes, your <Term id="shell" /> changes the text of the reference before `ferry` gets it.
</Callout>
