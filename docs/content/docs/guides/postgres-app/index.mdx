In this guide, you deploy a small notes API that uses <Term id="postgres" />. You create the database. Then you give its <Term id="connection-string" /> to the app with a <Term id="reference" />.

## The main command

```bash title="Terminal"
ferry up notes -e 'DATABASE_URL=${{datastore.notes-db.connectionString}}' --follow
```

## Before you start

You need a Ferry server that runs, and the `ferry` <Term id="cli" /> with a login to it. See the [Quickstart](/docs/getting-started/quickstart).
