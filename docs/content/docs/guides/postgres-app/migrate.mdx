This is a <Term id="one-off-job" />. See [Jobs & cron](/docs/concepts/jobs).

<Steps>
<Step>

### Run the migration

<Terminal
  lines={[
    '$ ferry run notes --follow -- npm run migrate',
    'Job job-48dd0201159b41c3bb58 pending, streaming output…',
    '==> Running `npm run migrate`',
    '> migrate',
    '> node migrate.js',
    'migrations applied',
    '==> Job succeeded',
    'Job job-48dd0201159b41c3bb58 succeeded (exit code 0)',
  ]}
/>

</Step>
<Step>

### Try the app

<Terminal
  lines={[
    "$ curl -X POST --data 'hello from Ferry' http://notes.localhost:8080/notes",
    'saved',
    '$ curl http://notes.localhost:8080/',
    '[{"id":1,"body":"hello from Ferry"}]',
  ]}
/>

The first command saves a note. The second command lists the notes.

</Step>
