<Steps>
<Step>

### Log in through the tunnel

```bash title="Terminal"
ferry login --server http://127.0.0.1:7878
```

The <Term id="cli" /> prints a code and opens a page of the dashboard.

</Step>
<Step>

### Approve the code

Make sure that the page shows the same code. Click **Approve**.

</Step>
<Step>

### Test the connection

```bash title="Terminal"
ferry info
```

The command shows your server: its default limits and its Docker host.

</Step>
</Steps>

Your terminal now has its own <Term id="api-token" />. You can revoke it under **Server → Account**. See [Set up the CLI](/docs/getting-started/cli).

## On the server, with no browser

Log in with the <Term id="server-token" />.

```bash title="Terminal (on the server)"
ferry login --token "$(sudo cat /var/lib/ferry/api_token)"
```
