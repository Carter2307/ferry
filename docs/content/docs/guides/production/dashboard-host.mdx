GitHub <Term id="webhook">webhooks</Term> and <Term id="deploy-hook">deploy hooks</Term> come from the internet. They cannot use your SSH tunnel. For them, serve the dashboard and the API through the <Term id="proxy" />.

<Steps>
<Step>

### Add the flag

Add `--dashboard-host` to `ExecStart` in the unit file.

```bash title="Terminal"
ferryd … --dashboard-host ferry.apps.example.com
```

</Step>
<Step>

### Restart ferryd

```bash title="Terminal"
sudo systemctl daemon-reload
sudo systemctl restart ferryd
```

The dashboard is now at `https://ferry.apps.example.com`.

</Step>
</Steps>

## The rules

- Each API call still needs an API token or a signed-in <Term id="browser-session" />.
- On a public base domain, the dashboard host is off unless you set it.
