This guide sets up one Linux server. Your apps answer at `https://<name>.apps.example.com`, with certificates from <Term id="lets-encrypt" />.

<Term id="systemd" /> starts <Term id="ferryd" /> at each boot. The <Term id="api" /> stays private.

## The main command

```bash title="Terminal"
sudo systemctl enable --now ferryd
```

This command starts `ferryd` now and at each boot. First do the pages of part 1, in order.
