<Steps>
<Step>

### Restore the data directory

Copy your <Term id="backup" /> of the <Term id="data-directory" /> to the new server.

</Step>
<Step>

### Start ferryd

Start `ferryd` with the same `--name-prefix` as the old server. This is the <Term id="name-prefix" />.

</Step>
<Step>

### Deploy each service again

```bash title="Terminal"
ferry deploy NAME
```

The built images are not part of a backup. For a service that you deployed from a local directory, use `ferry up`.

</Step>
<Step>

### Load your dumps

The <Term id="datastore">datastores</Term> come back empty, with their old credentials. Load your dumps into them.

</Step>
</Steps>
