---
title: Keep the secrets in a file
description: Put the secret options of ferryd in an environment file that only the user ferry can read.

Each flag of `ferryd` has an <Term id="env-var" />, except `--take-over`. Put the secret ones in an <Term id="env-file" />, not in the <Term id="systemd-unit" /> file.

<Steps>
<Step>

### Create the file

```bash title="/etc/ferry/ferryd.env"
FERRY_GITHUB_WEBHOOK_SECRET=paste-the-output-of-openssl-rand-hex-32
```

Replace the value with the output of `openssl rand -hex 32`.

</Step>
<Step>

### Protect the file

```bash title="Terminal"
sudo chown ferry:ferry /etc/ferry/ferryd.env && sudo chmod 600 /etc/ferry/ferryd.env
```

The user `ferry` owns the file. The <Term id="file-mode" /> `600` lets only the owner read it.

</Step>
</Steps>
