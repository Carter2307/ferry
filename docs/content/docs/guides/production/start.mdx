<Steps>
<Step>

### Load the unit

systemd reads the new <Term id="systemd-unit" /> file.

```bash title="Terminal"
sudo systemctl daemon-reload
```

</Step>
<Step>

### Start ferryd

```bash title="Terminal"
sudo systemctl enable --now ferryd
```

<Term id="systemd" /> starts `ferryd` now, and at each boot.

</Step>
<Step>

### Read the log

```bash title="Terminal"
sudo journalctl -u ferryd -n 30
```

The command shows the last 30 lines that `ferryd` wrote to the <Term id="journal" />.

```text title="Output (excerpt)" noCopy
  Ferry 0.1.0 is running
  Dashboard + API : http://127.0.0.1:7878
```

</Step>
</Steps>

## What the output tells you

| Line | Meaning |
|---|---|
| `Create your account` | The link that creates the account of the server. You open it on the next page. |
| `Docker` | The CPUs and the memory of the <Term id="docker-host" />. |
| `Limits` | The [container limits](/docs/guides/production/limits) that Ferry applies. |
| `Free disk check` | The [free-disk check](/docs/guides/production/disk-space) that Ferry applies. |

If a default limit is more than the host has, `ferryd` writes a warning at startup. It does the same if the kernel of the host cannot enforce CPU limits.
