---
title: The CLI cannot reach the server
description: The ferry command gets no answer at the address of the server.
---

## What you see

```text title="ferry" noCopy
Error: cannot reach Ferry server at http://127.0.0.1:7878 — is ferryd running?
```

Nothing answers the <Term id="cli" /> at that address.

## How to repair it

| Cause | Repair |
|---|---|
| <Term id="ferryd" /> does not run | Start `ferryd`. |
| The URL is wrong | Check `--server` or `FERRY_SERVER`. |
| The <Term id="ssh-tunnel" /> does not run | Open the tunnel with the command below. |

```bash title="Terminal"
ssh -N -L 7878:127.0.0.1:7878 you@your-server
```
