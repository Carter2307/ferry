---
title: Another ferryd uses the data directory
description: Only one ferryd can use a data directory at a time.
---

## What you see

```text title="ferryd" noCopy
Error: another ferryd is already running with data directory /var/lib/ferry
```

## Why it occurs

A second `ferryd` started with the same `--data-dir`. Only one server can use a <Term id="data-directory" /> at a time.

## How to repair it

- Stop the other process.
- Or give this `ferryd` its own data directory with `--data-dir`.
