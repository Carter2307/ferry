title: I forgot the password
description: Nobody can read the password of the account. Set a new password on the server.
---

## What you see

You cannot sign in to the dashboard, because you do not know the password.

## Why it occurs

No person and no program can read the password. The server stores only a <Term id="password-hash" /> of it.

## How to repair it

Choose a new password on the server with [`ferryd reset-password`](/docs/reference/server-options#ferryd-reset-password). Run it as the user that runs `ferryd`, with the data directory of the server.

```bash title="Terminal"
sudo -u ferry ferryd reset-password --data-dir /var/lib/ferry
```

| The command | Detail |
|---|---|
| Asks for the new password two times | It does not show the password. |
| Signs out each browser | <Term id="api-token">API tokens</Term> continue to work. |
| Works while the server runs | |

<Accordions>
  <Accordion title="In a script">
    When the input of the command is not a terminal, the command reads the new password from one line of <Term id="stdin" />.
  </Accordion>
</Accordions>
