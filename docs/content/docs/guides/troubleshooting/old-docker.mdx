---
title: Builds fail on an old Docker Engine
description: A service with environment variables needs Docker Engine 27.3 or newer for its build.
---

## What you see

```text title="Deploy log" noCopy
… (secret env mounts need Docker Engine 27.3 or newer: upgrade Docker on the Ferry server)
```

The deploy gets the status `build_failed`. The live deploy continues to answer.

## Why it occurs

The service has <Term id="env-var">environment variables</Term>. They go to the <Term id="build" /> as BuildKit secrets. A BuildKit secret is a <Term id="build-secret" />. The Docker Engine of the server is older than 27.3.

## How to repair it

Upgrade Docker on the Ferry server.
