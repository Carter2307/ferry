Ferry changes one machine with <Term id="docker" /> into your own <Term id="render" />. Docker is the only program that Ferry needs to run.

The server is one program, <Term id="ferryd" />. You control it from the <Term id="dashboard" />, the <Term id="cli" /> or the <Term id="api" />.

## Deploy the current folder

```bash title="Terminal"
ferry up
```
