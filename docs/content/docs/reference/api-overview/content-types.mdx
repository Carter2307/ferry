## The rules of a body

| Subject | Rule |
|---|---|
| The `Content-Type` header | The server does not require it. |
| An empty body | It counts as `{}`. |
| A field that the endpoint does not know | A 400 error. A wrong field name never passes with no effect. |
| [Source upload](/docs/reference/api/deploys#deploy-uploaded-source-code) | The <Term id="content-type" /> `application/gzip`: a `.tar.gz` of 512 MiB at most. |
| [Blueprint apply](/docs/reference/api/blueprints#apply-a-blueprint) | It also accepts raw YAML: `application/yaml`. |

The error for an unknown field:

```text noCopy
invalid JSON body: unknown field 'nope', expected one of 'name', 'type', 'repo_url', …
```

## Booleans in the query string

A <Term id="boolean" /> flag in the <Term id="query-string" /> accepts these values:

| Meaning | Values |
|---|---|
| True | `true`, `1`, `yes`, `on`, `y`, or the flag with no value (`?follow`) |
| False | `false`, `0`, `no`, `off`, `n` |
