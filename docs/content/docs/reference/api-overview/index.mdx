All that the <Term id="dashboard" /> and the `ferry` <Term id="cli" /> do goes through one JSON <Term id="rest-api" />. <Term id="ferryd" /> serves it.

These pages give the rules that each <Term id="endpoint" /> follows. The [API reference](/docs/reference/api) describes the endpoints one by one.

## Send a first request

The examples use <Term id="curl" />.

```bash title="Terminal"
# On the server itself: the server token. Elsewhere, an API token created in the dashboard.
export FERRY_TOKEN="$(cat ferry-data/api_token)"
curl -H "Authorization: Bearer $FERRY_TOKEN" http://127.0.0.1:7878/api/v1/info
```
