The <Term id="openapi" /> describes each <Term id="endpoint" /> of the API. Two tools read it.

## Where to read and try the API

| Tool | Where | Use |
|---|---|---|
| [API reference](/docs/reference/api) | These docs | Each endpoint with its parameters, bodies and responses. It comes from the OpenAPI document. |
| OpenAPI document | `/api/openapi.json` on your server | For tools that read the OpenAPI 3.1 format. |
| <Term id="swagger-ui" /> | `/api/docs` on your server | To send requests from a browser. |

## Send requests from a browser

The reference pages have no "try it" button, because `ferryd` sends no <Term id="cors" /> headers.

<Steps>
<Step>

### Open Swagger UI on your server

```text
http://127.0.0.1:7878/api/docs
```

</Step>
<Step>

### Click **Authorize**

Paste an <Term id="api-token" />.

</Step>
</Steps>
