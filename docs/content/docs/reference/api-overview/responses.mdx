## The status

| Endpoint | Status | Body |
|---|---|---|
| Creates a resource | `201` | |
| Puts work in the queue: a deploy, a restart, a rollback or a job | `202` | The deploy or the job in the queue |
| Deletes a resource | `204` | No body |

## The body

- The <Term id="request-body" /> of an answer is <Term id="json" />. Its fields are in <Term id="snake-case" />.
- A <Term id="timestamp" /> is in the <Term id="rfc-3339" /> format, in <Term id="utc" />: `2026-09-27T07:38:34.231568Z`.

## Writes to one service

The server does the writes to one service one after the other. Thus two requests on the same service at the same time never mix.
