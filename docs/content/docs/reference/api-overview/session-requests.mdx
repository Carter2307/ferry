`ferryd` checks where a change with the <Term id="session-cookie" /> comes from.

## The rule

The rule applies to a request that has these two properties:

- the session cookie is its proof
- its <Term id="http-method" /> changes something: `POST`, `PUT`, `PATCH` or `DELETE`

This request must come from the <Term id="origin" /> of the dashboard. If not, the answer is 403 `cross_site_request`.

## How ferryd checks

`ferryd` reads the header `Sec-Fetch-Site`. If the request does not have it, `ferryd` compares the header `Origin` with the host.

See [Changes come from the dashboard only](/docs/architecture/security/cross-site).
