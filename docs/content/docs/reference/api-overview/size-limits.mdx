## The limits of a request body

| Request | Limit |
|---|---|
| Each request, but not the two below | 2 <Term id="mib" /> |
| A source upload | 512 MiB |
| A <Term id="delivery" /> from GitHub | 25 MiB |

## The limits of variables

| What | Limit |
|---|---|
| The value of one variable | 32 <Term id="kib" /> |
| The <Term id="merged-env" /> of a service | 256 KiB |

See [Limits of keys and values](/docs/concepts/environment/limits).
