<Term id="sse" /> are a [standard of the web](https://html.spec.whatwg.org/multipage/server-sent-events.html). A <Term id="event-stream" /> is a plain HTTP answer.

## The streams

| Endpoint | Stream | Ends |
|---|---|---|
| `GET /api/v1/deploys/{deploy_id}/logs?follow=` | The build and deploy log of one deploy | After the saved lines. With `follow=true`: when the deploy is complete. |
| `GET /api/v1/jobs/{job_id}/logs?follow=` | The output of one job run | After the saved lines. With `follow=true`: when the job is complete. |
| `GET /api/v1/services/{id}/logs?follow=&tail=` | The runtime output of the current containers of the service | Without `follow`: after the recent lines. With `follow=true`: never. |
| `GET /api/v1/events` | The [change feed](/docs/reference/api-overview/change-feed) | Never |

## The headers of the answer

| Header | Value |
|---|---|
| `Content-Type` | `text/event-stream` |
| `Cache-Control` | `no-cache` |
| `X-Accel-Buffering` | `no`. With it, a proxy such as nginx does not buffer the stream. |

A <Term id="keep-alive" /> is the line `: keep-alive`.
