A <Term id="webhook" /> is a request that a different system sends to Ferry to start a deploy. The webhooks are outside `/api`. They never take an <Term id="api-token" />.

## The two webhooks

| Webhook | Path | Its secret | Trigger of the deploy |
|---|---|---|---|
| [Deploy hook](/docs/reference/api-overview/deploy-hooks) | `/hooks/deploy/{service_id}` | The key in the URL | `deploy_hook` |
| [GitHub webhook](/docs/reference/api-overview/github-webhook) | `/hooks/github` | The signature of the delivery | `webhook` |

See also [Deploy hooks](/docs/concepts/deploys/deploy-hooks) and [GitHub auto-deploy](/docs/guides/github-auto-deploy).
