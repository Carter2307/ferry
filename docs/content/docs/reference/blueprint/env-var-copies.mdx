---
title: Copy a variable with envVarKey
description: envVarKey copies the value of a variable of a different service during the apply.
---

```yaml title="ferry.yaml"
services:
  - type: worker
    name: worker
    envVars:
      - key: KEY
        fromService:
          type: web
          name: api
          envVarKey: TOKEN
```

`envVarKey` gives a copy, not a <Term id="reference" />. A later change of the source variable reaches the copy only at the next <Term id="apply" />.

`envVarKey` works only with services, not with datastores.

## Where the value comes from

1. From the blueprint, when the other service has that key in its `envVars`.
2. If not, from the saved environment of the service that exists.
3. If no one has it, the apply leaves the variable with no value and gives a warning:

```text noCopy
env var 'KEY' not copied: service 'api' has no variable 'TOKEN' yet
```
