The value of an <Term id="env-var" /> can be a <Term id="reference" /> to a <Term id="datastore" /> or to a different <Term id="service" />. You do not copy an address or a password.

Ferry saves the reference as you wrote it. When Ferry starts containers, it replaces the reference with the real value. Thus the value always agrees with its target.

## Set a reference

```bash title="Terminal"
ferry db create app-db --kind postgres
ferry env set api 'DATABASE_URL=${{datastore.app-db.connectionString}}'
```

The container of `api` then gets `DATABASE_URL=postgresql://app_db:<password>@app-db:5432/app_db`.

<Callout type="warning" title="Use single quotes">
Always put a value with a reference between single quotes. If not, your <Term id="shell" /> tries to expand `$`.
</Callout>
