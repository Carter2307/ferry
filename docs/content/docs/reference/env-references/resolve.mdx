Ferry resolves each <Term id="reference" /> at a <Term id="deploy" />, a <Term id="restart" /> or a <Term id="rollback" />.

## Who uses the saved environment

- the [reconciler](/docs/architecture/reconciler), when it replaces a crashed instance
- a scale up and a resume
- cron runs and one-off jobs

## If the target changes

When a datastore or a referenced service changes, the containers that run keep the old values. They keep them until the next deploy or restart.

To get the new values:

```bash title="Terminal"
ferry restart NAME
```
